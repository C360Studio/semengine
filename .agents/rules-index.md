# SemEngine Rule & Enforcement Audit Index

Canonical enforcement matrix for repository-wide rules and rules of agent conduct. `AGENTS.md` § "Rules and what
enforces them" carries the concise domain-grouped summary loaded into every agent session; this file carries the full
enforcement detail (exact test functions, sensitivity checks, scripts, and review-only coverage gaps).

The linked file in "Canonical home" is the rule; this table is only its index. "Review only" means no command fails
when the rule is broken. A change that adds a repository-wide rule or a rule of agent conduct (in a contract, the
protocol, `.agents/README.md`, or `AGENTS.md`) adds its row in both `AGENTS.md` and this file in the same change. A
capability spec's requirement gets a row only when it binds every change in the repository; the rest are indexed by
their spec. A change that can turn a "review only" row into a failing command should.
