# Task 1.1 and 1.2 notes (#201)

Choices the proposal does not spell out, and the evidence for the tests.

## Choices

- `ownerLive` (`internal/harness/natsfixture/admission.go`) drops its `host` parameter: once the host is not compared,
  nothing in it reads the value.
- The runner test `TestR1ForeignHostOwnerIsRespected` planted another host's name with a dead pid and required the
  lock to be respected, which is the behaviour #201 removes. It is now
  `TestR1LiveOwnerUnderAnotherHostNameIsRespected`: the same host name with this test process's pid and start time,
  still respected. The dead-pid half is a new case in `TestR2StaleLockIsQuarantined`, "dead pid under another host
  name", so it gets R2's full quarantine checks (status 0, "cleaned stale lock", nothing left at the lock path, go
  test ran under the runner's own record).
- In `TestAdmissionRequiresALiveOwner` the case "owner on another host" (live pid, refused for its host) became "owner
  pid is not a running process, under another host name" (refused as "not live"). The live half is a new subtest of
  `TestAdmissionAdmitsALiveOwner`, "a live owner whose record names another host". Its record is written out with
  `fmt.Sprintf`, as `TestAdmissionJudgesARecordWithoutIdentityUTCByIdentity` writes its own, rather than editing the
  host line of `ownerRecord`'s output.
- `TestR1BusyLockRefusesBeforeDocker` called `hostname(t)` twice, once for the record and once for the message it
  expects: the same two-read failure as #201's. It now reads the name once. `hostname(t)` stays; that test and three
  R2 cases use it to plant a record naming this machine.
- A lock directory with no owner file is still respected: `read_owner` leaves the pid `unknown`, and `owner_is_stale`
  returns 1 for a pid that is not a number. The spec delta now gives that reason ("its pid reads as unknown") instead
  of the host.
- Generated checks are not used. The judge reads one record, and the change removes one field from the decision; the
  named cases cover each pairing of a host name (this machine's or another) with a dead pid, a live pid with its start
  time, and a live pid with another start time.
