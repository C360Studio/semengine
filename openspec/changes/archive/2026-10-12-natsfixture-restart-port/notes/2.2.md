# Task 2.2 notes

`TestRestartPastAHeldPort` (`internal/harness/natsfixture/restart_port_integration_test.go`) starts the fixture,
reads its port P from `URL()`, listens on P+1 on all addresses with
`net.Listen("tcp", net.JoinHostPort("", strconv.Itoa(p+1)))`, restarts, then dials `URL()` and flushes.

## Choices

- **Its own file.** The test is in a new file so the same file runs on `main` unchanged; it uses only what `main`
  has (`startFixture`, `restart`, `stopBound`, `callCounts`).
- **A port it cannot hold is logged, not failed.** If P+1 is already taken, the test logs that this run may not
  reach the held-port path and goes on; failing would make the test flaky on a busy host.
- **What says the path was reached.** The test logs the stop-container call count after Restart: 2 means the first
  port read failed and Restart tried once more.
