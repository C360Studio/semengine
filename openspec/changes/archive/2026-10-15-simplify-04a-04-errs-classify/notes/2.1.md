# Task 2.1 notes: failing tests for "an unclassified error is fatal"

Base commit: `e52a509` (no production line changed). Tests only.

## What changed

- `pkg/errs/errs_test.go` `TestClassify`: the row `unknown error` (expected transient) became `bare error`
  (`errors.New("boom")`, expected fatal). The row `fatal word in message only` (expected transient) became
  `timeout and transient words in message only` (expected fatal), which keeps #146's text-does-not-decide check now
  that the default is fatal. Two rows added that already pass: a transient `*ClassifiedError` behind `%w`, and
  `context.DeadlineExceeded` behind `%w`, both transient.
- `pkg/errs/errs_test.go` `TestIsTransient`, `TestIsFatal`, `TestIsInvalid`: a `bare error` row each, expected false
  (spec scenario "A bare error"). These pass on the base commit and must keep passing after 3.1.
- `natsclient/errors_test.go` `TestClassForHeader_AllClasses`: row `unclassified_defaults_transient` became
  `unclassified_defaults_fatal`.
- `natsclient/errors_test.go`: new `TestRespondError_RoundTripUnclassifiedIsFatal`, a sibling of
  `TestRespondError_RoundTrip` (which stays on its coded invalid error). It builds the reply the way `RespondError`
  does for `errors.New("marshal failed")` and checks the header is `fatal`, and that the requester's error reads
  `errs.IsFatal` true and `errs.IsTransient` false.

## Not named by the design

`natsclient/errors_integration_test.go` `TestIntegration_RequestClassified_RoundTripPreservesClass` had a row
`unclassified_plain_error_defaults_transient` asserting the old default through a real `SubscribeForRequests` handler
and `RequestClassified`. Design D1 and task 2.1 do not name it, but it would fail once 3.1 lands, and it is the
end-to-end form of the transport-client spec scenario "A plain handler error". It became
`unclassified_plain_error_defaults_fatal` with handler error `errors.New("marshal failed")`, expecting `IsFatal` true
and `IsTransient` false. A repository grep for `default.{0,6}transient` / `defaults_transient` in Go files found no
other assertion of the old default.
