# Task 2.1 notes

Test: `TestHelperEndsWhenItsTestProcessEnds` in `internal/harness/prochost/prochost_test.go`, rows `killed`,
`interrupted`, `returned`, `panicked`.

## Choices the design does not spell out

- **Reason text.** The test asserts that the grandchild's stderr contains `test process ended` (the constant
  `helperExitReason`). Task 3.1 writes a line containing that text when a helper exits because its stdin reached
  end-of-file.
- **Two new helpers.** `park` (the grandchild) is the existing `block`: it catches only SIGTERM. `parent` (the
  helper-parent) runs `helperParent(t)`, so `TestHelperProcess` now names its `*testing.T` and the helper-parent's
  nested `Start` uses it.
- **The record.** The helper-parent writes the grandchild's pid, `ps lstart` start identity and stderr path to
  `HELPER_DIR/grandchild` (write to `.tmp`, then rename), and the outer test reads it with `probe.Await`.
- **Go-ahead for the self-ending rows.** The helper-parent registers for SIGTERM before it starts the grandchild and
  parks on it after writing the record. In `killed` and `interrupted` the outer test sends SIGKILL (`Kill`) or SIGINT
  (`Signal`), which end it there. In `returned` and `panicked` the outer test sends SIGTERM as the go-ahead, after it
  has confirmed the grandchild is running; the helper-parent then returns from `fn` (`Helper`'s `os.Exit(0)`) or
  panics from a goroutine it starts. SIGTERM is caught, so it is not what ends the process in those rows.
- **Setup guard.** Each row asserts how the helper-parent ended (SIGKILL; SIGINT; exit 0; exit 2) before checking
  the grandchild, so a row that ended the helper-parent the wrong way fails on that line, not on the grandchild.
- **Outer cleanup.** It SIGKILLs the grandchild's process group (`-pid`; the grandchild leads its own group) only when
  the pid still has the recorded start identity, then waits up to `failureBound` for it to be gone. Its context is
  `context.WithTimeout(context.Background(), failureBound)`: `t.Context()` is already cancelled when cleanups run.
