# 2.3 `TestContractCloneIsIndependent` and 3.5 `contract.Contract.Clone`

Test: `pkg/projection/contract/contract_test.go`. The expected value is a second literal built by the same
`build` function, never the original or the implementation, so "unchanged" is checked against what the test
wrote. It changes a group's name, a predicate in each group and a birth predicate on the clone, then checks the
original. A contract with no groups is cloned too: its clone must equal it, nil `Groups` included.

Failing on the base commit `dc8d01b` (compile failure on the missing method):

```text
pkg/projection/contract/contract_test.go:72:20: original.Clone undefined (type Contract has no field or method Clone)
pkg/projection/contract/contract_test.go:86:19: sparse.Clone undefined (type Contract has no field or method Clone)
FAIL    github.com/c360studio/semengine/pkg/projection/contract [build failed]
```

Mutation check: a copy of `contract.go` whose `Clone` copies the groups but not each group's predicates.

```text
task mutate:check -- -pkg ./pkg/projection/contract -test TestContractCloneIsIndependent \
  -file pkg/projection/contract/contract.go -mutant "$TMPDIR/clone-mutant/shallow.go" \

verdict: detection: each of the 3 mutant runs failed the named test with an expected line, and the after-run passed
```

Choices the design does not spell out:

- `Clone` uses `slices.Clone`, which keeps a nil slice nil. The two copies it replaces turned nil `Groups` into an
  empty slice; nothing reads the difference (validation and JSON's `omitempty` treat both as empty), and
  `payloadregistry` and `pkg/projection` tests pass unchanged.
- `payloadregistry.cloneContracts` stays: it is the slice loop over `Clone`, read at `registry.go:245` and `:282`.
- Ledger: the `pkg/projection/contract` row is `adapt`, its contract line names `Clone`, and its `known_risks` no
  longer says `pkg/projection` is absent. The `payloadregistry` row (already `adapt`) is not edited: the change
  there replaces a private helper with `Clone` and changes no behaviour.
- Generated checks: not used. The law is "no shared backing array"; one contract with every slice field filled,
  plus one with nil groups, reaches each field `Clone` copies.
