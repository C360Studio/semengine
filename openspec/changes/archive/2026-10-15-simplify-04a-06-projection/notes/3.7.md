# 3.7 Every `ReadAuthoritative` failure is not committed (#267)

`ReadAuthoritative` returns `notCommittedError(MutationOperationReadAuthoritative, err)` for every read failure. It
does not ask the write mapping (design D1).

Choice the design does not spell out: the kind and class of an unclassified read failure. They follow the same rule
as any not-committed failure: the class is `errs.Classify`'s (transient for a no-responder error), and the kind is
by class. So `natsclient.ErrNotConnected` (wraps `errs.ErrConnectionLost`) reads transient, `MutationUnavailable`;
`nats.ErrTimeout` reads fatal, `MutationInternal`. Before this change both read commit-unknown. A classified read
reply keeps its class, code and kind as before.
