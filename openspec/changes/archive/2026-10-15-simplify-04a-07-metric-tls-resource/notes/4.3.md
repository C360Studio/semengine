## Failing on the base

Base commit: `7b388ad60e6f3824eb345a5fad8a3f3d628377a1` (branch `claude/simplify-metric-tls-resource`), with
`internal/resource/watcher.go` unchanged and `TestWatcher_WaitForStartup_NilContextRefused` added to
`internal/resource/watcher_test.go`. The test's check returns nil and counts its calls; the test asserts
`WaitForStartup(nil)` returns false and the count is zero.

On the base the check ran once with the nil context and the result was true, as design D5 states.

## Choices

- The test passes the nil context through a typed variable (`var nilCtx context.Context`), as
  `TestWatcher_Run_NilContextRefused` and other tests in the repository do, so lint does not flag a literal nil.
- The test does not use `testing/synctest`: with the fix no timer is reached, and on the base the check succeeds on
  the first attempt, so neither path waits.
- The startup-retry timer (`time.After`) is unchanged (owner answer Q4).
