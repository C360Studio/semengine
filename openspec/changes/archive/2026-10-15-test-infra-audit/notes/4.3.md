# Task notes: 4.3

Choices made adding `TestNoParallelIntegrationTests` and `TestOwnServerReason`, each with its paired sensitivity test, in
`internal/harness/contract/testtext_test.go` (`design.md` B6 and B7; `specs/harness-boundaries/spec.md` "Integration
tests in a package run one at a time" and "A test with its own server says why").

## Rulings and where they are implemented

| Ruling | Where |
| --- | --- |
| No `t.Parallel()` in a Go file carrying `//go:build integration`, with paired sensitivity test | `internal/harness/contract/testtext_test.go`: `TestNoParallelIntegrationTests`, `TestNoParallelIntegrationTestsSensitivity`, `parallelIntegrationViolations`, `hasIntegrationBuildTag` |
| Every `natsfixture.New` call in a `*_test.go` file outside `internal/harness/natsfixture` carries `// Own server: <reason>` on the line above, with paired sensitivity test | `internal/harness/contract/testtext_test.go`: `TestOwnServerReason`, `TestOwnServerReasonSensitivity`, `ownServerViolations` |

## Choices

- Both checks live in `internal/harness/contract/testtext_test.go` alongside `TestNoSleepsInTests`, `TestNoSkippedTests`,
  `TestNoHiddenTests`, and `TestNoBareSelect`, using `repoFiles` and `writeTree`.
- Both checks strip any trailing `//` line comment (`codeBeforeLineComment`) before matching `t.Parallel(` or
  `natsfixture.New(`, so prose comments explaining the rule do not false-positive.
- `ownServerCall` matches `natsfixture.New(` (with the opening parenthesis) so `natsfixture.NewFaultKV(` is not treated
  as an own-server call (`TestOwnServerReasonSensitivity` includes `natsfixture.NewFaultKV(nil)` in its clean fixture).
- `ownServerViolations` checks that `strings.TrimSpace(lines[i-1])` starts with `"// Own server:"` and has non-empty
  reason text after the colon (`TestOwnServerReasonSensitivity` checks missing comment, non-matching comment, and empty
  reason `"// Own server:   "`).
- Both violation functions fail when their file filter matches zero files (`tagged == 0` or `tests == 0`), matching the
  existing empty-scan guard in `scanTestText` and `bareSelectViolations`.
- Before task 4.4's migration, running `go test -v -run '^(TestNoParallelIntegrationTests|TestOwnServerReason)'
  ./internal/harness/contract` passed `TestNoParallelIntegrationTests`, `TestNoParallelIntegrationTestsSensitivity`, and
  `TestOwnServerReasonSensitivity`, and failed `TestOwnServerReason` naming all 13 unmigrated `natsfixture.New` call
  sites across `component`, `graph/kvcatalog`, `natsclient`, `pkg/lifecycle`, and `processor/graph-ingest`.
