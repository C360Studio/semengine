# Task 4.4 notes

- **`natsclient` helper split (`natsclient/test_helpers_integration_test.go`):** `startFixture(t)` now takes no
  `natsfixture.Option`s and returns an unexported `sharedFixture` carrying only `URL() string` over `shared.Reset(t)`.
  That keeps the 44 `startFixture(t).URL()` call sites across the shared tests unchanged while ensuring `startFixture`
  serves shared tests only and exposes no `*natsfixture.Fixture`. `newFixtureClient(t)` resets the shared server and
  calls `newFixtureClientAt(t, url)`, which the three `WithMaxPayload` own-server tests in
  `natsclient/request_response_bounds_integration_test.go` also call after starting their own `natsfixture.New`.
  `(tc *fixtureClient).stream` creates its stream through `tc.Client.JetStream()`.
- **`natsclient` `TestMain` / `run` teardown failure (#241, #253):** `run(m *testing.M) int` in
  `natsclient/test_helpers_integration_test.go` matches the other four migrated packages: it captures `code := m.Run()`,
  stops `shared` under a 1-minute bounded context, prints any `shared.Stop` error to `os.Stderr` and returns `1`, and
  otherwise returns `code`. `TestIntegration_SharedServerStopFailureExitsNonZero` spawns a child test process that
  resets the shared server and removes the child's container in a `t.Cleanup` registered before `shared.Reset(t)` (so it
  runs after `shared.Reset`'s post-test connection check), proving that when `m.Run()` returns `0` and `shared.Stop`
  fails in `TestMain`, the process exits with status `1` and prints an exact `PASS` line followed by
  `natsfixture: stop container`.
  - Verified failing first against `8415260` (`child exited <nil>`).
  - Verified with `GOFLAGS=-tags=integration task mutate:check` on `internal/harness/natsfixture/shared.go` (injecting
    `t.Error("injected child failure")` before `return url` in `Reset`) that a failing child test cannot satisfy the
    parent assertion (`verdict: detection` at `test_helpers_integration_test.go:208: child output must contain an exact
    PASS line before the stop error`).

  `natsfixture.Open(t, url, openFixtureClient)`, and creates each requested stream through `client.JetStream()`. The

  two restart tests in `processor/graph-ingest/guard_generation_integration_test.go` keep `natsfixture.New(t)` with
  `// Own server: restarts the server mid-test.`.
