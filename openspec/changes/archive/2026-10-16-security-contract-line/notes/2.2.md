## Choices the design leaves open

- The refusal names the key and, for `mode`, the value: the test requires `mode "acme"` or `mode "amce"` in the
  message, and `acme.enabled` for the ACME block.
- A fourth refused case, `mode` `"manual"` with `acme.enabled` true, holds that the ACME check does not depend on
  `mode`.
- The server cases enable server TLS. With server TLS disabled the server loader returns before it reads any other
  server setting (`internal/tlsutil/tlsutil.go:23-25`), as it already does for `min_version` and as the spec's
  second requirement states for `metric.NewServer`; the refusal follows that order, so a disabled server block is
  not refused for its `mode`.
- The metrics-server test is named `TestServerRefusesACMEMode` and checks "serves nothing" as its sibling
  `TestServerRefusesMTLSWithoutTLS` does: the listener stays with the caller and the server holds no serving state.
