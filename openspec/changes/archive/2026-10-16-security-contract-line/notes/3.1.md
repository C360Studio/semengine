## Choices the design leaves open

- One unexported helper, `checkManualMode(mode, acme, method)`, serves both loaders, since `ServerTLSConfig` and
  `ClientTLSConfig` share no type that carries `Mode` and `ACME`. Its `method` argument keeps each loader's name in
  the error, as the existing refusals do.
- The server loader checks after its `!cfg.Enabled` return (see `notes/2.2.md`); the client loader, which has no
  enable switch, checks first.
- `mode` is checked before `acme.enabled`, so a configuration with both wrong names `mode`.
