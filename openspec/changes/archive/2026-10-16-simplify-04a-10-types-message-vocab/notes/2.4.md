## 3.6 choices the design leaves open

- `Contracts` sorts with `sort.Slice` on `Key()`, as D6 says, not on the components: the two orders differ when one
  component is a prefix of another (`a` against `a-b`, since `-` sorts before `.`).
- `Registration.MessageType` builds a `types.Type` and returns its `Key()`; no unexported helper was added.
- graph-ingest: `canonical_mutations.go:218` passes `entity.MessageType`; the `key` string above it stays, since the
  error detail and message still name the key text. `component.go:677` keeps `containerType`, now a `types.Type`; its
  error message formats it with `%s`, which `Type.String` (`Key()`) makes the same text. No other line of either file
  changed.

`TestContractsReturnsIndependentSortedCopies` strengthened (coordinator's follow-up on the PR, fixed here rather than
filed). Its old two keys sorted the same by `Key()` and by component, and with two keys a missing sort passed about
half the time. It now registers five types out of order: `agentic.loop_execution.v1` (contracts `zeta`, `alpha`),
`a.x.v1`, `agentic.agent_lesson.v1`, `agentic.loop_execution-x.v1` and `a-b.x.v1`. `a-b` and `loop_execution-x` sort
before `a` and `loop_execution` by key (`-` is before `.`), but after them by component. The oracle is the six
key/name pairs written out literally in key-then-name order; nothing in the test sorts.

Mutation check: a copy of `payloadregistry/registry.go` whose `Contracts` sorts by domain then category instead of by
`Key()`, run with

```bash
task mutate:check -- -pkg ./payloadregistry -test TestContractsReturnsIndependentSortedCopies \
  -file payloadregistry/registry.go -mutant "${TMPDIR:-/tmp}/mutant.go" -expect attributes_test.go:194
```

exit 0, verdict `detection: each of the 3 mutant runs failed the named test with an expected line, and the after-run
passed`. The failing line: `Contracts()[0] = a.x.v1/a-record, want a-b.x.v1/a-b-record (ordered by key then name)`.
This mutant was chosen over deleting the sort because its failure is deterministic; deleting the sort leaves map
order, which would match the six expected pairs by chance in about one run in 120.
