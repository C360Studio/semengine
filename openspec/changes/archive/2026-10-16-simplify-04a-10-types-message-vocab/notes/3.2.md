# 3.2 BaseMessage.Validate calls Type.Validate

Choices the design does not spell out:

- The type refusal now wraps `Type.Validate`'s own error with `errs.WrapInvalid` (action `invalid message type`)
  instead of wrapping the `errs.ErrInvalidData` sentinel with the type's key. It is still classified invalid
  (`errs.IsInvalid`), and its text now names the failing component. No caller here tests `errors.Is` against
  `errs.ErrInvalidData` for this refusal (`git grep -n ErrInvalidData -- '*.go'`).
- Two comments that described the old check were corrected: the doc of `TestBaseMessageRefusesTypeThatIsNotUTF8`
  (`message/meta_wire_test.go`) and `indexingProfileMetricLabel`'s doc (`processor/graph-ingest/component.go`),
  which said `IsValid` checked only that all three components were present.
- `MarshalJSON`'s meta source UTF-8 check stays: D2 removes only the type loop.
