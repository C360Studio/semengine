## Choices

- The negative-count test checks the handler count before and after each call (`MaxAttempts` 0, then -1), so each
  call is shown to run the handler exactly once.
- The refused-config test proves "never sent" the way the replaced test did: a valid request sent afterwards on the
  same connection is the only one the handler sees. It asserts only that an error comes back; the class is not
  promised (design D2).
