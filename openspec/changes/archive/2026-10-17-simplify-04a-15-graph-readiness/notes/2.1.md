# Task 2.1 notes

Base production code: `graph/readiness/watcher.go` at `ad6b0f7`, unchanged by this task.

## What the rewrite does

- Every Watcher test in `watcher_test.go` runs in a `synctest.Test` bubble, with each fake channel made inside it. A
  delivery is a send on the fake watch's unbuffered channel followed by `synctest.Wait()`. Time moves with
  `<-time.After(d)` on the bubble's clock, which is the clock `Read` and `apply` read through `time.Now`. None of
  `withClock`, `withRebindDelay` or `withAppliedHook` is used; the 5-second wall-clock guards are gone.
- The rebind wait is the real one-second constant. `TestWatcher_MissingBucketIsUnknown` now asserts one open before
  the wait and a second one after one second of bubble time; `TestWatcher_RebindsAfterWatchLoss` asserts two opens.
- `fakeSource` counts opens with an `atomic.Int32` instead of signalling a channel.
- `TestWatcher_AlreadyStaleOnArrivalIsUnknown` writes its window as `3 * heartbeat` rather than calling
  `FreshnessWindow`, so the oracle is the requirement, not the code.
- `TestWatcher_UndecodableValueDoesNotRefreshFreshness` also asserts `Age` is the good value's age, which pins that
  the garbage stamped no arrival.
- `TestWatcher_RunValidatesWiring` builds each watcher inside its bubble. The heartbeat and logger rows wait for 2.2:
  on the base they would pass `NewWatcher` options that the base silently ignores.
- `TestFreshnessWindow` tests a pure function and runs no goroutine, so it is not wrapped in a bubble.
- `publisher_test.go`'s round-trip test used the watcher harness, so its watcher half now runs in a bubble too
  (`newHarness(t, DefaultHeartbeat)`). It is the only caller of the harness outside `watcher_test.go`; nothing
  else in that file changed.

## New test

`TestWaitForFirst`, four subtests: released by a decoded envelope (and a second call returns at once); released by a
stale-on-arrival envelope, which `Read` still reports not fresh; `context.DeadlineExceeded` when nothing arrives
within the context's minute; not released by a tombstone or an undecodable value, with the same waiter released by
a decoded envelope afterwards as the control.
