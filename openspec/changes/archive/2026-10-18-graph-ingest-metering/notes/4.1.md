Choices the design does not spell out:

1. The class is read with `errs.Classify`, which answers fatal for an unclassified error, as the wire does
   (`natsclient/errors.go`, `classForHeader`). The code is the outermost classified error's, or empty.
2. Three of the four invariant failures cannot be reached from a test: a JSON string cursor (`:389`) and a response
   whose entities already encoded one by one (`:435`) always encode, and the fitting check (`:438`) holds by
   construction. The table drives the fourth, `:363`, by calling `marshalFittingPrefixPage` with an entity whose
   object is `+Inf`, which `encoding/json` refuses; entities read from the bucket cannot carry one.
3. The maximum-payload row calls `handleQueryPrefixNATS` on the test component's unconnected client, whose
   `MaxPayload` fails.
4. `TestQueryBatchEmptyIDsRepliesAnEmptyResponse` is not named in the design. It holds the declared change to the
   empty-IDs reply (`:118`), which no test pinned before.
