Choices the design does not spell out:

1. The component is built by `CreateGraphIngest` (through `createTestComponent`) and not started, as
   `TestIntegration_TypedClientPreservesCommitAmbiguity` does: the test sets the entity bucket to the `FaultKV`
   wrapper and gives the component an entity cache (`cache.NewSimple`), which only `Start` builds. With no `Start`,
   no goroutine reads the fields the test sets.
2. The append goes through `addTriplesLane`, the mutation append lane's body, and the delete through
   `deleteEntityAtRevision`, the delete lane's body, so each failed write reaches the write seam the way a request
   does. The batch query goes through `handleQueryBatchNATS`, which reads the cache.
3. E's refused value and how it is recorded copy `TestIntegration_BootSweepInventoriesResidentPoisonRealNATS`: raw
   bytes with a two-part predicate, recorded by an entity query that refuses them.
