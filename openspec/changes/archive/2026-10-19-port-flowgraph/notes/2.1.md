# Task 2.1 notes

Choices task 2.1 made that the design does not spell out.

- The pin's `README.md` is not copied in this task. Task 2.1 names the three `.go` files; the README arrives with
  its R5 corrections in task 2.2, so no pin text that the design calls untrue lands on its own.
- `doc.go`'s two package links at the pin (`:163-164`) name the module path, so the module-path rewrite changed them
  too. Their text (including "`service` uses flowgraph") is task 2.2's R5 correction.
- `TestFlowGraphConstruction`'s empty-graph case reads `AnalyzeConnectivity().DisconnectedNodes` (empty) where it
  read `GetNodes()`; the one-node case reads one disconnected node named `test-component`.
- `TestBuildFromDeclarationsRefusesNetworkBindConflicts` puts the input and the output on one component
  (`gateway`), the case the design's Q4 paragraph names as the one the registry accepts and `flowgraph` refuses.
- The declarations in `declarations_test.go` are built with the pin's own `testPortFacts` helper
  (`component_node_test.go`), which projects each port through `component.Port.Facts`, as the registry does.
- The refusal and the build-error assertions match full error text where nothing later in the change rewrites it
  (the count-mismatch and missing-identity refusals). The graph-mutation and network-conflict assertions match a
  fragment, because R14 (task 2.4) changes the wrapping around them.
