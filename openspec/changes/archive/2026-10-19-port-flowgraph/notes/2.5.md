# Task 2.5 notes

Choices task 2.5 made that the design does not spell out, and the mutation record.

## Conflict texts in operator words (before the mutants)

- After task 2.4 the network-address and KV-bucket conflict texts still printed component/port pairs in Go's struct
  format (`[{first listen} {second listen}]`; `notes/2.4.md` left them as the pin wrote them). This note supersedes
  that bullet. On the owner's word of 2026-10-19 for simple leftovers ("let’s fix them so we do not create debt on
  simople fixes as we port"), each pair is now printed as `component <name> port <port>`, the form the graph-mutation
  refusal already used (`flowgraph.go:227`), joined by `", "`. One unexported helper, `describePorts`
  (`flowgraph.go`, above `exclusivePortRefs`), builds it for the three conflict texts; no owner of this formatting
  existed before (the only other pair form in the package is that refusal's own `fmt.Errorf`).
- The connection ID in each text is printed as the port's facts give it, unchanged: `tcp:0.0.0.0:8080` for a network
  address and `kv:entity_states` for a KV bucket.
- `TestRefusalsNameNoInternalFunction` gains the case `two conflicts at once` (two writers to one KV bucket and two
  exclusive binds on one network address), asserting the full text, so the `"; "` join and the order (the KV text
  first, as `connectComponentsByPatterns` collects them) are checked. The `network bind conflict` case's and
  `TestBuildFromDeclarationsRefusesNetworkBindConflicts`' `one input and one output` expected texts were changed to
  the new form.
- Red first, on d46a966's code: `TestRefusalsNameNoInternalFunction/network_bind_conflict`,
  `TestRefusalsNameNoInternalFunction/two_conflicts_at_once` and
  `TestBuildFromDeclarationsRefusesNetworkBindConflicts/one_input_and_one_output` failed, each printing the
  `[{... ...}]` form. The test's first draft expected `KV bucket entity_states`; the red run showed the connection ID
  is `kv:entity_states`, and the expectation was corrected to it before the fix (the text prints the ID as the
  network text does). Green after the fix at 06481f2 (`go test -race ./internal/flowgraph`, `task lint`).
- The ledger row's `contract`, `README.md` and `doc.go` quote no conflict text, so none changed.
