Each wrong change is the design's ("Proving tests and mutants"), made in a copy under `/tmp/lfp-mut/` (outside the
repository) of `internal/logforwarderpolicy/policy.go` at commit `a8d24a173df22ed6ef8e4fc55873ca9971c83ba3`, with
the pin's line numbers (the file is byte-identical to the pin). Every run used the same command shape:

```bash
task mutate:check -- -pkg ./internal/logforwarderpolicy \
  -test TestResolveOwnsDefaultsNormalizationValidationAndSafetyExclusion \
  -file internal/logforwarderpolicy/policy.go -mutant /tmp/lfp-mut/<ID>.go -expect <location>
```

Defaults: seed 1, three baseline runs, three mutant runs, one after-run. The reports were written to
`/tmp/lfp-mut/<ID>.log`, on the developer's machine only.

## Choices the design did not spell out

- The test: every mutant names `TestResolveOwnsDefaultsNormalizationValidationAndSafetyExclusion`, since every
  mutated line is reached through `Resolve`. M6 is also visible to that test: its `rejects invalid level` case sends
  `TRACE`. `TestValidateFieldsPreservesPublicConfigValidationSemantics` sends lower-case `trace`, so M6 would survive
  it.
- The expected location: the assertion the wrong change should break. That is `policy_test.go:40` for a missing
  refusal, `:43` for an unexpected error, `:44` for the level, and `:45` for the exclusions. Each survivor names the
  assertion it would break if a case covered it.
- M4 deletes the whole `if _, exists := seen[source]; exists { return }` block (`:80-82`). The `seen[source] = ...`
  write stays, so the copy builds. M6 adds `"TRACE"` to the `case` list at `:65`. S2 deletes `:77-79`, and S3
  deletes `:76`.
