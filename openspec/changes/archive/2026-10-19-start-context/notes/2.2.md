# Task 2.2 notes: the two checks and the settle window (D1-D3)

## Choices the design leaves open

- Removal detection is a membership test (`missing` in `lifecycletest.go`, `slices.Contains`): an item listed before
  the Start context ended and not listed after it is reported. The adapter contract names each retained kind once, so
  repeats are not counted (simplified at `c73718a`; see "Pre-Codex review" below).
- The settle-window wait also selects on the check's own context, so a test that ends during the window gets an error
  instead of a wait.
- The abort cause `errAbortCause` is renamed `errStopCause` ("lifecycletest: Stop context ended"), since the check no
  longer models an abort.
- `errors_test.go` (`TestChecksPropagateOwnerFailures`) names the new checks; its three cases keep their meaning.
- `TestAbortStopThenFinishJoinsWorker` keeps its name (design D4 lists it as a proving test) and calls
  `CheckStopReturnsItsEndedContext`.
