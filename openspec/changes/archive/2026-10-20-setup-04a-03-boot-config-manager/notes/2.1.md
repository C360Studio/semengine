## Choices the design does not spell out

- **Adapter `Calls` is empty.** Design D2 says "`Calls` counts the adapter's own `Start`/`Stop` calls". Built that
  way, the suite fails by construction: `RepeatedStopIsNoOp` and `SecondStartRefusedOrRestartCycle` compare the whole
  `Observation` before and after a call (`internal/harness/lifecycletest/lifecycletest.go:243-294`), and that call
  adds one to its own count. The server-side watch count is listed in `Unresolved` as
  `watch consumers on the server`. Observe polls it with `probe.Await` until it equals the Manager's own watcher
  count, bounded at 5 s. The design line needs correcting. This is flagged for the architect, not decided here.
- **Encoding-failure driver is a service.** D4 says to drive `TestPushEncodingFailureFailsStart` with a component
  whose `config` is `json.RawMessage("{")`. A probe on the scratch copy showed that this never reaches the push.
  Start applies the platform identity before arbitration, and `Mutate` validates the whole configuration, which
  decodes each component's ports: `config validation failed: streams: decode component "broken" ports: unexpected
  end of JSON input`. The test would pass at the pin for that reason. A service whose `config` is `"{"` does reach
  the push. At the pin, Start logged `marshal service broken: ...`, returned nil, and left `version` and
  `services.s1` in the bucket. The test uses that service. Flagged for the architect.
- **First-boot encoding case.** The identity record is minted before the push, so the test checks only that no
  `services.*`, `components.*` or `version` key exists (D4's wording). The spec delta's "A refused Start ... a value
  that cannot be encoded ... SHALL leave the bucket's contents unchanged" holds key for key only in the newer-file
  case, which the test asserts. If the first-boot case should hold as well, the encoding check must run before the
  mint, and the spec sentence and D4 need to say which.
- **Bad-name rows:** `a.b`, `a*` and `>`, for a service and a component each. Q2 names the dot, `*` and `>`. A
  component named `a b` is accepted and written as `components.a_b`.
- **NATS key case rows:** `token` and `Token`. Both must name `nats.token`.
- **Lifecycle-suite owners** each declare their own pair (`acme`/`suiteN`), so each owner has its own bucket and
  backing stream to count. The must-fail owner's bucket is seeded with a foreign identity record, so Start acquires
  the bucket and then refuses.

## What tasks 2.2 and 2.3 must satisfy that the design does not say

- **Unexported names the tests read:** `acquireBucket`, `publishBucket`, `store`, `bucket`, `pushToKV(ctx,
  *natsclient.KVStore) error`, `handleUpdate(key, value, revision)`, `matchesPattern`, `engineHighWaterRev`
  (`atomic.Uint64`), `bucketName`, `natsClient`, `config`, `logger`, `subscribers map[string][]chan update`, `mu`
  (`sync.RWMutex`), `watchers []jetstream.KeyWatcher`, `errBucketNotAcquired`, `errFamilyNotRegistered`,
  `platformIdentityKVKey`, `platformIdentityRecord`, `managerWatchPatterns`, and `KeyFamily.bind`. A
  `&Manager{config, subscribers, logger}` literal must be usable as is (`manager_reconcile_test.go`).
- **New field `workDone []chan struct{}`**, guarded by `mu`: one channel for each goroutine the Manager starts
  (watch processors, family processors, model-registry forwarders), closed when that goroutine returns. Observe
  reads it under `mu.RLock`, together with `subscribers` and `watchers`. This is the "done channel Stop waits on"
  that D2 names. The suite needs it to be the real join, not a mirror kept for the test.
- **After a Stop that returns nil, `watchers` must be empty** (nil or zero length), and `subscribers` must hold no
  channel. At the pin the slice survives Stop, so Observe would report `watchers` as held.
- **Error text:** a refused name contains the name. A malformed stored service contains `services.metrics`. A
  stored NATS token contains `nats.token`, which `rejectUnappliedNATSKeys` already writes. An encoding failure
  contains the service name (`broken`).
- **Bad names are refused before the bucket is created.** `TestNameThatIsNotOneKeyTokenIsRefused` requires
  `GetKeyValueBucket` to fail after the refused Start. `DeleteComponentFromKV` refuses a bad name as well as
  `PutComponentToKV` does.
- **Concurrent Stops** may be refused as transient by `lifecycleguard`. The concurrent-shutdown test ignores those
  errors and requires that a Stop after all of them return nil.
- **`task verify` at this commit fails by design.** The package does not build until 2.2 lands. `tasks.md`'s "Each
  task ends only when `task verify` passes" cannot hold for 2.1. Its gate is the failing compile, recorded above.
  On this commit: `task lint`, `task fmt:check`, `task docs:check` and `go test ./internal/harness/contract/` pass.
