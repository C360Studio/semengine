# Notes on task 2.1

Base: `36399e9a33d72436d907ba93889d88f68bde7a3c`, go1.26.10 darwin/arm64, GNU bash 3.2.57.

## Choices the design leaves open

- The bound is `specQueueBound`, 10 seconds, the value of the precedent at
  `message/generic_json_shape_test.go:166`. One run takes about 0.2 seconds here.
- `runSpecQueue` sets `cmd.WaitDelay = time.Second`. Without it, a child of the script that still holds the output
  pipes when bash is killed would keep `Run` waiting, and the bound would not hold. The loop in #262 is in bash
  itself, so the base run ends without it; the line is for a hang in a child.
- `ctx.Err()` is checked before the exit status, and the failure names the arguments and says the run "did not end".
- A refusal row requires standard error to be exactly `--stale-days needs a whole number of days` and a newline,
  standard output empty, exit 2. An A4 row requires the `ok` line through `requireReported` and empty standard
  error. A5 requires standard error to be exactly `unknown argument: --bogus` and a newline, exit 2.
- Every row uses `listOneChange` and the one-task `tasks.md` `- [ ] 2.1 (D) Write the reader.`, which carries no
  caveat.
