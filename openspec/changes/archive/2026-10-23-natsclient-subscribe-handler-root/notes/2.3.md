# 2.3 Message logger

`start` now subscribes under its Start context and checks that context once more after the loop, before the retry and
the "MessageLogger started" record (design D2). The ended-context branch of `handleMessage` writes one Warn record,
"Message dropped: its handler context has ended", with `subject` and `error`, and counts `dropped_messages`, which
`GetStatistics` serves (D3). `runCtx` and `runCancel` stay; only their comments changed (D4).

## Choices the design does not spell out

- T6 reads the record's level and its `subject` and `error` attributes, as Codex's design PASS asked; the design's
  `holdingHandler.arrived` sees only message text. It reuses `recordingHandler` from `service/pprof_test.go`, which
  keeps each record, so no new helper and no production hook were added. It reads `/stats` through the mounted route,
  as `TestStatsCountsOnlyTypedEnvelopesValid` does, and checks `errors.Is(error, context.Canceled)`.
- T5 lives in `message_logger_suite_integration_test.go` beside `messageLoggerOwner`, the suite adapter whose held list
  it reads. It holds the Debug "Subscribed to subject" record, cancels the Start context, then releases the record.
- The final check wraps the context's error as transient, as the loop's check does, with the detail "context ended
  after the last subscribe".
- `subscribeSubject`'s parameter is renamed from `runCtx` to `ctx`, since `start` and the retry both pass theirs.
- `service/doc.go`: beside the `/stats` list (`:354-356`, which gains `dropped_messages` and the drop), the Start
  paragraph's "ctx bounds Start only" is rewritten to D2's wording, including R1's exception; it was stale in the same
  way as the `Start` doc comment.
- The `TestMessageLoggerStopDrainsInFlightMessage` comment names mutant M6 (D5); the run-context mutant it named is
  equivalent now.
- 30 repeated runs of T5, `TestMessageLoggerKeepsCapturingAfterStartContextEnds`,
  `TestMessageLoggerStopDrainsInFlightMessage` and `TestMessageLoggerPassesTheLifecycleSuite` under `-race` passed.
