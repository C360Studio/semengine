## Uncovered (design, Sensitivity)

- **A publish in progress when `Stop` begins whose call ignores its context (D2).** `Stop` ends the run context and
  waits for the loop (`<mf>:184-194`). A round passes the run context to `PublishToStream` (`<mf>:165`); how soon a
  publish already inside nats.go sees that context end depends on nats.go honouring it, which nats.go does not promise.
  `Stop` stays bounded by its own context either way, and `TestMetricsForwarderFailedStopIsRetried` covers a loop that
  cannot return (held in its log call); no test holds the loop inside the publish itself, so the publish's own
  cancellation is not tested. No mutant applies.
- **H7, retained.** A failed gather skips the whole round (`<mf>:156-160`), including the samples the gather did
  return. Retained as the design records; `TestMetricsForwarderGatherFailureIsCounted` asserts the skip, and check 21
  covers the count, so no further mutant applies.
- **H8, retained.** A label value is spliced into the subject unvalidated (`<mf>:241-246`). The design (D4) retains it:
  such a publish is counted like any other, which check 20 covers for a publish that fails. No test drives a label
  value that makes a bad subject, so how such a publish fails is not tested here; no mutant applies.
