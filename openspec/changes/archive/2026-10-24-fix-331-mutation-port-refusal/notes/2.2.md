## The fix

- `processor/graph-ingest/canonical_mutations.go`: the refusal in `requireMutationProviderPort` for a first
  graph-mutation input that is not valid reads `graph mutation provider port %q must be a required %s %s nats-request
  input on %s`, with `definition.Name` as the first argument (design D1). The check order, the `ambiguous` and
  `required` texts, and the callers' wrapping are unchanged.
- `docs/admission-ledger.yaml`: item (8) of the `processor/graph-ingest` row's `contract` gains `; a first
  graph-mutation input that is not valid is refused with an error naming the port (#331)` before
  `(one-mutation-port-check, #323)` (design D3), wrapped like the rest of the folded scalar.
