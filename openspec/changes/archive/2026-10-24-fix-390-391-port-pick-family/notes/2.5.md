## Choices the design does not spell out

- A scan failure exits with git grep's own status (128 for a bad pattern), not 1, so it cannot be read as a found
  fixed port; a violation still exits 1 and a clean tree 0.
- Output names files without the `./` prefix (`x/x_test.go:3:` where `grep -r` printed `./x/x_test.go:3:`); the
  existing test matches `x/x_test.go:3:`, which both forms contain.
- The freePort paragraph of the header says the pick is on `tcp4` and points at `freePort`'s doc comment for why,
  rather than restating the measured claim there.
