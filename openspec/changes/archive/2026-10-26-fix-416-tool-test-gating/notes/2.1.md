# Task 2.1: the Task probe, repeated

Repeated on 2026-10-26 with Task 3.51.1 (`task --version`, matching `.task-version`), in a scratch directory
`/tmp/416probe/` outside the repository. Task behaved as the proposal states (`Taskfile.yml` bullet), so task 4.2
is not held.

- A `sh:` variable whose command exits 3 fails the task with exit 1, and none of the task's commands runs: no
  `task: [failvar]` line and no `command ran` output.
- A variable whose command prints `a b c` reaches the command as three words (`argc=3`).
- `-- ./x` replaces the default in `{{.CLI_ARGS | default .PKGS}}` (`argc=1`, `arg=./x`); without `--` the
  default is used.

## Taskfile

`/tmp/416probe/Taskfile.yml`:

```yaml
version: '3'

tasks:
  failvar:
    vars:
      PKGS:
        sh: echo partial; exit 3
    cmds:
      - echo "command ran with {{.PKGS}}"

  words:
    vars:
      PKGS:
        sh: echo a b c
    cmds:
      - sh -c 'echo "argc=$#"; for a in "$@"; do echo "arg=$a"; done' probe {{.PKGS}}

  override:
    vars:
      PKGS:
        sh: echo a b c
    cmds:
      - sh -c 'echo "argc=$#"; for a in "$@"; do echo "arg=$a"; done' probe {{.CLI_ARGS | default .PKGS}}
```
