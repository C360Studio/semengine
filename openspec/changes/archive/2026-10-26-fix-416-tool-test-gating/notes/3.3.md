## Choices the proposal does not spell out

- Every list prints packages as `./<dir>`, `unit` included, so the three lists share one form and the tool packages
  are named once, as directories. `unit` turns each `go list ./...` import path into `./<dir>` by removing the
  module path (`go list -m`). A tagged test file at the module root is listed as `.`.
- Lists are sorted with `LC_ALL=C sort -u`, so the order does not depend on the locale.
- `test-pkgs.sh` with no argument or an unknown one prints its usage and exits 2.
- `git grep` exits 1 when nothing matches, so "no tagged file" and "git grep failed" share one message and exit 1.
- Both scripts `cd` to the repository root (`$(dirname "$0")/..`), as `scripts/tree-state.sh` does, so the tests run a
  copy in a planted tree.
- `tools-changed.sh` holds the trigger paths in one array. The skip message prints it. A trigger ending in `/` matches
  every file under it, and any other trigger matches only that exact path.
- In CI, untracked files are not added, as the proposal says: only the local run adds them.
- A `pull_request` run with `GITHUB_BASE_REF` unset compares against `origin/`. `git merge-base` then fails, so every
  tool test runs and the output names the missing merge base.
- The script runs `task test:tools` with `exec` after printing `tool tests run: <why>`, so the exit status is that of
  `task test:tools`.

## Planted cases beyond the brief

- `TestTestPkgsLists` also plants an ignored tagged file (`.gitignore` names `ignored/`), which is not listed. The
  spec reads "tracked or untracked, unignored".
- It plants a module whose only package is `internal/harness/toolcheck`, so `unit` is empty, and checks for a
  non-zero exit. Without this case the empty-list guard survived its mutant: no other case reached it.
- It checks that an unknown list name exits non-zero.
- The untracked tagged file has spaces before and after `//go:build integration`, which the trimmed match accepts.
- In `TestToolsChanged`, the pull-request case uses a base branch named `release` and plants no `origin/main`. A
  script that compared against `origin/main` would run every tool test there, and the case would fail.
