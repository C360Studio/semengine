- The pin reader is one function, `ateamPins` in `internal/harness/toolcheck/ateamtemplates_test.go`, used by
  `TestAteamTemplatesUnchanged` and by `TestCIWorkflowPinned`. Besides "one version across both files" it fails when a
  file has no install line at all, so dropping the install step from `merge-check.yml` (which would leave the gate
  without a binary) fails the contract test and `scripts/doctor.sh` rather than CI.
- `scripts/doctor.sh` and the test's version-mismatch message now say to put `$(go env GOPATH)/bin` first on `PATH`,
  since the common local failure is a development `ateam` build ahead of the pin.
