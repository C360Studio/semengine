## Rewritten

| Pin test | Change |
| --- | --- |
| `TestClassifierChain_ContextCancellation` | both subtests now assert `nil` (design D4); the pin accepted nil or the default result. The timeout subtest used a 1 ns timeout and `time.Sleep(10 * time.Millisecond)`; it now takes a deadline already in the past, so the context has ended before the call |
| `TestFindBestMatch_ContextTimeout` | same: a deadline already in the past instead of a 1 ns timeout and `time.Sleep(10 * time.Millisecond)` |
| Every `NewEmbeddingClassifier(domains, threshold)` call | `mustNewEmbeddingClassifier(t, domains, threshold)`, a test helper that calls the new constructor under `t.Context()` and requires no error (owner answer 2) |
| `createTestEmbeddingClassifier`, `createTestEmbeddingClassifierWithThreshold` | take `t` to reach that helper |

Every `context.Background()` in the kept tests became `t.Context()`. The header
`// Code generated by Tester Agent. DO NOT EDIT.` (with two lines naming a SemStreams task) was removed from three
files: the files are hand-maintained here, and the marker would make tools treat them as generated.

Three lint fixes the repository's `revive` asks for, no behaviour change: `var c *EmbeddingClassifier = nil` and
`var chain *ClassifierChain = nil` lose the `= nil`, and `TestClassifierChain_ConcurrentAccess`'s goroutine drops its
unused `id` parameter (`for range numGoroutines { go func() { ... }() }`).

No other assertion changed. The pin's weak oracles (S12: temporal tests that assert `NotNil` only) are kept as
optional findings (design D6).
