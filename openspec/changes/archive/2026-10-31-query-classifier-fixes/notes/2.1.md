## Choices the design leaves open

- The oracle for "read-only" is a second classifier built from the same examples and asked nothing else, plus the
  same classifier's own score before the traffic. The traffic repeats words of the question unevenly
  ("temperature" many times, "alarms" once), so folding it into the statistics moves the relative word weights.
- "Construction still learns" is shown by two classifiers whose last example is the same and whose earlier examples
  differ (one corpus has a second document with "alarms" and "pumps"). With no learning every word's weight is the
  default 1.0 and the scores would be equal; the test asserts they differ.
- `FindBestMatch`'s and the type's doc comments, and the README "Limits" line, now say the query is embedded with
  `GenerateQuery`.
