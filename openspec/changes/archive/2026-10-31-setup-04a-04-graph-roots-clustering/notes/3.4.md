<file> -mutant <copy> -expect-text <text>`, three baseline runs and three mutant runs each, `-race`, Rapid seed 1
(the tool's default). Every mutant is a copy outside the repository; the tool reports commit `2ab0fdd`, tree
fingerprint `e5696ebcc0ae` before the first run and after the last, no uncommitted changes. The location column is
the line Go printed for the first mutant run (a `t.Helper` closure prints its caller's line).

Integration tests: `mutcheck` has no build-tag flag, so each wrong change was copied over the file from a `cp` backup,
the test run with `go test -tags integration -count=1 -run '^<test>$' ./graph/clustering`, and the file restored. A
baseline run of the four tests passed first. SHA-256 before and after, matching: `storage.go`
`bce7f9ba0a4ed0dbda31fbf2dca17579c54a24df5daa1ae59a72ffa9ff164243`, `maintainer.go`
