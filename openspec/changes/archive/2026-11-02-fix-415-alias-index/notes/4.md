## Choices the design leaves open

- **Oracle.** The test compares the code with the literal `"alias_ambiguous"`, not the constant, and requires the
  message to contain `"shared-1"` (quoted, as `%q` prints it).
- **Second alias predicate.** `test.identity.serial`, registered as an identity alias before graph-index starts
  (it discovers alias predicates in `startIndexPool`) and restored with `defer vocabulary.SnapshotRegistry()()`.
- **Refused twice.** The test refuses, lets E2 drop the alias (answers E1), gives it back (refused again), then
  deletes E2 (answers E1): the second refusal shows the drop step did not remove E1's row either.
- **Delete ordering.** As in `TestAliasReadImplementsReplacement`, a later write's revision orders the read after
  the delete's apply.
- **Message.** Kept from task 3: `alias "<alias>" is held by <n> entities`. Only the code changed; the
  `// shortcut:` marker went with it.
