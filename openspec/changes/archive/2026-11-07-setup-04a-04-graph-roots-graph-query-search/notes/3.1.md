## Choices the design leaves open

1. **The chain is built per call.** `routeGlobalSearch` builds `query.NewClassifierChain(query.NewKeywordClassifier(),
   nil)` each time rather than holding it on `Component`: the keyword classifier is an empty struct and its patterns
   are package variables (`graph/query/classifier.go:22`, `:31-55`), so there is nothing to share and no field to add.
2. **A path counts as a filter only with a start.** "Two of path, time, area" counts a path when it names a start node.
   Path words with no start beside a time range ("what is related to it in the last 2 hours") are therefore not two
   filters; the time range is not the question's only hint, so it is D2's refusal. The test has that row.
3. **The typed read fails closed.** An option key the keyword tier does not send (another tier's `strategy`, say), or
   a value of another type, including a typed nil `*TimeRange` or `*SpatialBounds`, is refused transient `internal`,
   never read as absent (`TestGlobalSearchRefusesHintsItCannotRead`). `aggregation_field`, `limit` and
   `path_predicates` (which the tree's keyword tier no longer sends, PR #475) count as hints no strategy honours.
   `path_start_node` without `path_intent` counts as path.
4. **The classifier's error is read by class.** An invalid-class error (`numbersOutOfRange`, the only one the chain
   returns, `classifier_chain.go:96-98`) becomes `invalid_request`, its text kept, so the phrase is named; any other
   class would be transient `internal`. An impossible number wins over two filters, since the chain refuses before
   any hint is read ("what is connected to pump-42 in the last 0 days").
5. **Counting the ended classification is 3.2's.** The route returns transient `internal` for a nil result; `Health`
   is counted by the handler, which 3.2 adds. `TestGlobalSearchEndedClassification` checks class, code and message;
   the `Health` half of the spec scenario lands with the handler.
6. **Entity routing is the route's answer, not the reply.** "forklift" and "the area of the plant" route to `entity`
   and `path` here (one token; a zone start `area-of`, per `notes/probes/step4-tree-probe.log`); the spec's
   `text_search_unsupported` for both comes from 3.2's resolver finding no entity (D3).
7. **Messages.** Two filters: `invalid request: the question names two filters, a path from pump-42 and a time range;
   ask with one` (three: `three filters, a path from pump-42, a time range and an area`). Ended: `internal error: the
   question's classification ended with the request: context canceled`.

## Generated checks or examples

Examples suffice: the route reads at most six facts (path, start, time range, area, an unhonoured hint, one token),
and D1's table plus its five mixed rows name each combination the keyword tier produces. A generated check over hint
combinations would restate the table as code, with no independent oracle. The fuzz target covers the bytes:
`FuzzDecodeGlobalSearchRequest` decodes, then routes any accepted query, and asserts a coded refusal or a strategy
carrying what it reads.

- Seed replay: 9 seeds, run by every `go test` of the package (passes).
- Exploration (local only): `go test -run '^$' -fuzz FuzzDecodeGlobalSearchRequest -fuzztime 15s
  ./processor/graph-query/`: 523,831 execs, 187 new interesting inputs, no failure.
