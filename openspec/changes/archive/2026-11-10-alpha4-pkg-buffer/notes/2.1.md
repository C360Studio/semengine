## Found, not in the design

`NewCircularBuffer` returns `newCircularBuffer`'s `(*circularBuffer[T], error)` as `(Buffer[T], error)`, so
on a metrics-registration error the returned `Buffer[T]` is a non-nil interface holding a nil pointer
(`buffer.go`, `return newCircularBuffer(capacity, opts)`). A caller testing `buf != nil` sees a buffer. Not
fixed here; `TestMetricsOnInjectedRegistry` asserts only the error. Raised with the orchestrator for a
ruling on whether 2.2 fixes it or it is filed.
