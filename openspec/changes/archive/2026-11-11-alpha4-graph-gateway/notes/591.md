# Issue 591 notes: data kept for an executed query with no included root

Codex review of PR #588 at 2ec752ae found that a query whose only root field is skipped
(`{ entity(id: "x") @skip(if: true) { kvRevision } }`) encoded as `{}`: execution leaves an empty, non-nil `Data`
map and `omitempty` drops it. GraphQL execution results carry `data`. The fix tags `response.Data` `omitzero`, so only
a nil map (a request refused before execution) leaves `data` out.

`TestExecutedQueryKeepsData` checks the bytes `writeResponse` writes: every root skipped (`@skip(if: true)`,
`@include(if: false)`) answers `{"data":{}}`, `@include(if: true)` answers the field, and a refused mutation has
`errors` and no `data`.
