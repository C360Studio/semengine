# Task 4.1 notes: the websocket output in the composed stack

Choices the design leaves open.

- **When the client connects.** `TestSmoke_OneConfigAnswers` connects after the fixed writes are indexed, so the
  snapshot carries a `put` per fixed entity and `synced`; a put the view had not yet applied arrives as a change
  and is folded the same way. The same client then follows the edit and the delete.
- **Oracle.** The fold (key to revision and payload) must equal `ENTITY_STATES` read back key by key, and its keys
  must be exactly the entities the test published (minus the deleted one). Frames are read until one at or above the
  bucket's revision, which `awaitIndexed` read with nothing written after it, so no wait depends on timing.
- **Health ordering.** The output reads `degraded` until its view is caught up, and the view retries every 5 s
  (`viewRecheck`) while graph-ingest has not yet created `ENTITY_STATES`. Every health read in the package follows
  `awaitIndexed`, so `awaitIndexed` now ends with `awaitStreamed`, which waits on two separate events. Stream
  convergence: a client the output accepts streams through the revision, then closes. Health: `/components/health`
  is polled until the output reads healthy. A streamed snapshot does not order the health read, because the view
  admits clients before its caught-up hook publishes the output's health (Codex review, PR #592 comment
  6805844726). A view stuck degraded now holds the wait until `go test -timeout`.
- **Port.** `freeLoopbackPort` picks in `tcp4` on `127.0.0.1`, the address the output binds (#390); a restart
  reuses it, as it reuses the HTTP and metrics ports.
- **Shown able to fail** (Go `-overlay` on `output/websocket/state.go`, tree untouched, SHA-256 checked before and
  after; `task mutate:check` does not run integration-tagged tests): a delete frame sent as `put` fails at the
  post-delete fold; a put frame one revision high fails at the first fold; a live view reporting `catching up` never
  passes the health wait (run under `-timeout 90s`: timed out). Codex's scheduling probe (view opened 5 s late, the
  caught-up hook's health store 250 ms late) failed the health read before the health wait existed and passes with it.
