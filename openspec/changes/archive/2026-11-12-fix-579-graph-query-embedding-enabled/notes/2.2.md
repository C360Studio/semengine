## Choices the design leaves open

- The off handler is chosen in `queryHandlers` by the row's responder (`graph.ResponderGraphEmbedding`), not by the
  verb names: `semantic` and `similar` are the only rows that forward there. A row whose subject is gone still gets
  no handler, so `Start` still fails naming it.
- The unit test's requests cover a valid search, a valid similar, bytes that are not JSON, and no body: the invariant
  is "whatever the bytes". Named examples suffice, since the handler never reads them.
- In the integration test `similar` names an entity graph-embedding has no vector for; graph-embedding would answer
  that with its own `embedding_unavailable` refusal, so a forward would have been answered either way.
