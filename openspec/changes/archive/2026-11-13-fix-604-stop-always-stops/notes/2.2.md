## Implementation

- `service/service_manager.go`: `Manager.StopAll` refuses only `nil` `ctx`, returns `nil` before `StartAll` when no
  listener is held, and passes any non-nil `ctx` through `stopAll` so every started service and listener initiates stop
  in reverse order while returning `ctx.Err()` if `ctx` had ended and synchronous stops returned `nil`.
- `service/component_manager_lifecycle.go`: `ComponentManager.stopComponents` removes the `ctx.Err()` `continue` skip,
  initiating reverse-order `comp.Stop(ctx)` and store deregistration across every remaining started component while
  retaining components whose `Stop(ctx)` failed for retry on a later `Stop`.
- `service/message_logger.go` and `service/metrics.go`: fence `watchesClosed` and `lifecycleCalled` unconditionally on
  any non-nil `Stop`, and initiate `endWatchStreams()` + `runCancel` in `MessageLogger.cleanup` even if an earlier drain
  returned `ctx.Err()`.
- `service/heartbeat.go`, `service/metrics_forwarder.go`, and `service/storage_observability.go`: initiate
  `BaseService.Stop(ctx)` even when loop join outlasts `ctx`, joining errors via `errors.Join`.

- `service/component_manager_lifecycle_test.go`: aligned `TestComponentManagerStopTimeoutStillStopsRemainingComponents`'s
  `spec:` reference and made `providerA`'s non-holding cleanup synchronous so the "finished cleanup does not re-run on
  retry" assertion executes deterministically on every run.
