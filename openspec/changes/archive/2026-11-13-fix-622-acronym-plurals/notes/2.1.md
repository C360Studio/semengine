# 2.1 Tests first

Tests added or changed:

- `TestAcronymPluralsMeetTheirSingular` (`graph/lexical/index_test.go`): one entity per form (`ID`, `id`, `IDs`,
  `ids`, and the same four for URL, API, PR, ADR, UUID); each form as a query must return exactly its group's four
  entities. The groups and their entity IDs are written by hand; `Tokens` computes nothing expected.
- `TestTokens`: cases "acronym plurals" (`IDs IDS URLS CPUs UUIDs ids` gives `id id url cpu uuid id`), "a capital
  run before a word is unchanged" (`HTTPServer`), "an acronym plural inside a run is unchanged"
  (`EntityIDsByType` gives `entity i ds type`; `by` is a stopword).
- `TestPluralRules`: `id ids` and `pr prs` join the pairs that meet; rule 5's bound witnesses are now `its`→`it`
  (3 bytes folds) and `os`→`os` (2 bytes does not); `bus`→`bus` keeps the `us` exclusion.
- `FuzzTokens`: seed `IDs ids URLs`.

Generated checks: none added. The laws the change must keep (folding twice equals folding once; tokenizing the
joined words gives them back) are `TestPropFoldIsIdempotent` and `FuzzTokens`; the acronym rule adds no new law, so
the table of examples suffices.

Commands: `go test ./graph/lexical/ -count=1 -run 'TestTokens|TestPluralRules|TestAcronymPluralsMeetTheirSingular|FuzzTokens|TestPropFoldIsIdempotent'`,
go1.26 darwin/arm64. The two halves were run by `-overlay` with a copy of `tokens.go` kept outside the tree: rule S
only (rule 5 back at `n > 3`), rule F only (the end-of-run `s` drop removed).
