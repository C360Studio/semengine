# 2.2 Implement rules S and F

Rule S sits at the top of `splitIdentifier` (`graph/lexical/tokens.go`): a run of three or more runes whose last is
a lower-case `s` after two capitals loses the `s` before the case split, so the capitals stay one part. Rule F is
plural rule 5's bound in `fold`, `n > 2` instead of `n > 3`. The `Tokens`, `splitIdentifier` and `fold` comments,
`graph/lexical/doc.go` and the README's "How text becomes words" name both rules and rule F's merges (`its`/`it`;
`TLS` to `tl`, `CAS`/`CA`, `ios`/`io`; `10s`/`10`; `ins` and `DOS` dropped, a `DOS`-only query refused with
`ErrEmptyQuery`). Each of those statements was run through `Tokens` and `ParseQuery` in a throwaway test kept
outside the tree (added by `-overlay`) before it was written; all held.
