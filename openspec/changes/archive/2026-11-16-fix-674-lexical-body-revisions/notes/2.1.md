## What changed in the test

- `keyModel` holds the latest text, the latest reference (nil for none), that reference's body state and the last
  reference the key named (so "keep" can re-name a reference after a delete or a no-reference write).
- `mustDeliver`'s read expectation follows the model: a read is wanted unless the reference is the same whole value
  and either the text is the same or a read of it is still queued. The returned read must name the model's reference.
- A read return applies when the latest revision names the read's reference and its body awaits a read; it then makes
  the latest revision due. Otherwise it is dropped and makes the read's own revision due.
- Completion: the model records each due completion (`outcomes`); a delivered revision must be complete exactly when a
  due completion of its key at or above it, made no earlier than its delivery, exists. Same rule as before, expressed
  as model completions rather than per-delivery outcome steps, because a same-reference revision's outcome is now
  another revision's read.
- The repair pass's expected reads include the reference.
- `TestStaleBodyReadDropped` gives R+1 its own `bodyKey` (`fresh`), so R+1 is a reference change.
- `text` in `apply_test.go` gains `contentType` and `size`, written into the reference.
- Shared references: a delivery can name another key's last reference, so several keys share one body word.
  `checkKey` now wants each word found on exactly the keys whose model expects it, not on one key alone. The witness
  "two keys share a reference" returns key b's read while key a also waits on that reference (a's body must not be
  indexed by it), sends telemetry-only revisions on a, then moves b to a new reference: b drops the shared body word at
  once and a keeps it, with no read asked for a.
- `TestDeliveriesAndBodyReadsConcurrent` (owner's intent: no race when text and telemetry mix on the same or similar
  entities): each key now changes its name and reference at its own pace. Key 0 changes both every round (the earlier
  stress); key 1 its name every third round and its reference every seventh, so most of its revisions are
  telemetry-only; key 2 its name every other round under a reference it never changes. Every fifth round has no
  offloaded body. The final check is the last name and the last reference's body, and no other name or body word.
