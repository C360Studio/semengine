# Task 2.4 notes: the Worker's 30 s embed bound

## Where it is

- `graph/embedding/worker.go`, `generateOne`: the one embedder call runs under
  `context.WithTimeout(ctx, embedTimeout)` (`embedTimeout = 30 * time.Second`, unexported, no knob). When `Generate`
  fails and that context has ended, the error wraps the context's error (`%w (embedder: %v)`), as
  `graph/entitytext/body.go` does for a body read. `classifyEmbedErr` is unchanged: its `errors.Is(err,
  context.DeadlineExceeded)` arm files the record `timeout`.
- The bound sits in `generateOne`, inside the singleflight call, so peers sharing one call share its deadline.
- When the Worker's own context ends first, the wrap carries `context.Canceled`, so `markFailed` still treats it as a
  shutdown, as before.

## Test

`graph/embedding/worker_hungembedder_test.go`, `TestHungEmbedderFreesWorkerLane`, two subtests under
`testing/synctest`, one lane (`WithWorkers(1)`), no NATS (the in-memory KV fakes):

1. `context_error`: the fake blocks the first record's call until its context ends and returns `ctx.Err()`.
2. `plain_error`: the same, but it returns `errors.New("embedder gave up")`, which wraps nothing and names no timeout.

Each asserts the first record is failed `timeout` at exactly 30 s of fake time, the second is generated at the same
instant, and the first record is stored failed. Named examples suffice: there is one input (the embedder's answer at
its deadline) with two classes, both written out.

## An existing test changed

`TestWorkerPassesExactRunContextThroughWatcherIOEmbedderAndCallbacks` (`review_findings_test.go`) asserted the
embedder received Run's context itself (`require.Same`). With the bound it receives a descendant, so the test now
asserts what D4 states: the embedder's context carries Run's value and has a deadline. The callbacks are still
asserted to receive Run's context unchanged. `task verify` on the first commit (19bd5af8) failed on this assertion.

## Not covered

- An embedder that returns vectors after its deadline: the vectors are used, as a body returned whole is.
