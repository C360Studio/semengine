# 2.1: tests first

`TestDeclaredWidth` in `graph/embedding/httpembedder/httpembedder_test.go`. One embedder built with
`Config{Dimensions: 3}` against a provider that answers 2 wide for the text `narrow` and 3 wide for anything else:

- `Dimensions()` is 3 before any request, and the provider has seen no request at `New`.
- The first request gets a 2-wide reply. It is refused with an error naming 2 and 3, no vectors are returned,
  and `Dimensions()` stays 3. The refused reply comes first on purpose: with a learned width, a first reply of any
  width is accepted, so this is the case only a declared width can refuse.
- A 3-wide reply is then accepted, and `Dimensions()` is still 3.
- `New` with `Dimensions: -1` returns an error.

`Dimensions: 0` keeps the learned width: `TestRefusesUntrustedReply`, `TestNewRefusesConfig` and the three
`TestHTTPEmbedder_Dimensions*` tests are unchanged and pass.
