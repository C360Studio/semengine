# Task 2.3 notes: choices the design leaves open

- **The compiled pattern lives in an unexported field** `pattern *regexp.Regexp` on `ConditionExpression`. "Compiled
  from the current value" is `pattern.String() == Value`, so one field answers both the uncompiled and the edited
  case; no second copy of the source text is kept.
- **Characters, not bytes.** The 500 limit counts runes (`utf8.RuneCountInString`), as the ruling says "characters";
  the pin counted bytes. Equal for ASCII; `TestCompileAccepts/500_two-byte_runes` pins it.
- **A refusal changes nothing.** `Compile` builds every pattern first and writes them only when all succeed, so a
  refused slice is never half-prepared (`TestCompileRefusals` checks the good element before the bad one stays
  uncompiled).
- **Regex is dispatched outside the operator map.** Its function needs the condition, not only the two values, so
  `applyOperator` sends `regex` to `matchRegex`, and `RegisteredOperators` adds `OpRegexMatch` as it adds
  `OpTransition`. The pin's `operatorRegex` is gone.
- **Error shape.** `errs.Classified(errs.ErrorInvalid, ...)` with the message
  `condition <i> (field "<f>", operator "regex"): <reason>`; the regexp error is wrapped with `%w`. `Load` (PR 2)
  prefixes the rule ID, file and list name.
- **Token match is plain `strings.Contains`** for each of `SubstitutionPrefixes()`, so `^\$now` is refused too: the
  substituter would still rewrite its `$now`.
- `regex_cache.go` is renamed `regex.go`; `regex_cache_test.go` is deleted whole (its cases test the cache and the
  dropped complexity checks; its safe patterns that still matter are in `TestCompileAccepts`).
