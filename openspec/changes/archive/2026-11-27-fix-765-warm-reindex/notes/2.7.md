## The test

`TestDeletingRecordsRebuildsEveryEntity` (`record_rebuild_integration_test.go`) deletes one INCOMING row by hand while
graph-index is stopped. A start with the records in place answers without it (the declared limit), so the test can
tell the reset from any restart; after the record bucket is deleted while stopped, the next start answers it again and
records both entities clean. Examples suffice: there is one input, the reset or not.
