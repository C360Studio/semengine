Detection: both the warning and the counter assertions fail.

## Choices the design leaves open

- **Fixture.** `src` now also carries `core.identity.alias` = `alpha-1`, so the well-formed alias row exists. That
  adds the alias predicate to `predicateList`; its expectation gains `{core.identity.alias, 1}`, sorted first.
- **No deleted-after-listing case.** The alias read lists keys and reads no values, so a row deleted after the
  listing cannot be read as malformed; there is nothing to exclude.
- **Generated checks.** Not used: one malformed key under one prefix is the whole input class the requirement names;
  the key grammar is the one `entityAndPredicate` already parses for NAME.
