# Task 2.4: `natsclient/storagereport` watchOnce stops through `kvwatch.Stop`

## Test

`TestIntegration_ReportConsumer_RunLeavesNoWatchDelivery`
(`natsclient/storagereport/storage_report_consumer_integration_test.go`, shared server from
`fixture_integration_test.go` through `startFixture`). One client (closed in cleanup through `closeClient`) creates
bucket `STORAGE_REPORT_BACKLOG` and puts 600 report rows (above nats.go's 256-entry updates buffer). Then 10 cycles,
each a fresh `Consumer` over a test-side `ReportWatchStore` (`backloggedWatchStore`):

1. the store's `WatchAll` opens the real `kv.WatchAll(ctx)`, waits for `natsfixture.AwaitNativeDeliveryBlocked`, sends
   the result on `blocked`, then waits for `<-ctx.Done()` before it returns the watcher;
2. the test receives from `blocked`, then cancels, so the hand-off is ordered after the cancel;
3. `Run` returns (bounded by `failureBound`), and `natsfixture.AwaitNoStacks` over `natsfixture.NativeDeliveryStacks`
   finds no delivery left.

No production hook: the store is passed to `NewConsumer` as any caller's store is.

## Test watchers

`fakeKeyWatcher` (`storage_report_consumer_test.go`) and `service`'s `fakeReportWatcher`
(`service/storage_observability_http_test.go`) get `closeUpdates` (a `sync.Once` around `close`); each `Stop` calls
it. The lost-watch closes in `storage_report_consumer_test.go` (`TestReportConsumer_ReestablishesADroppedWatch`),
`storage_report_resync_test.go` (four) and `reviewer_storage_snapshot_probe_test.go` (two) call it. A fake's `Stop`
runs only when `watchOnce` returns, after its updates closed or its ctx ended, and no test sends after that.
`service`'s store hands back the same watcher on every `WatchAll`; the `sync.Once` keeps a second `Stop` from closing
twice.

Unit run time, `go test -count=1 ./natsclient/storagereport/ ./service/`: before 0.291s / 3.720s; after
0.341s / 3.726s, 1.405s / 4.732s, 0.273s / 3.532s (a first run right after the integration gate read 3.789s /
6.951s under load; `-v` shows no storagereport unit test above 0.00s). No test waits out `kvwatch.DrainBudget`.

## Choices the task left open

- **Context passed to `kvwatch.Stop`.** `watchOnce`'s own `ctx` (`Run`'s). On a closed-updates return it may still be
  live; the drain then sees the closed channel at once. The drain is bounded by `kvwatch.DrainBudget`, counted after
  the watcher's `Stop` returns, whatever ctx is doing.
- **Log.** `kvwatch.Stop`'s error is logged at Warn as "could not stop the storage report watch" with `error`; it was
  discarded before. `kvwatch.Stop` drops the benign "already gone" errors, so the real-server path logs nothing;
  `TestReportConsumer_RunWarnsWhenTheWatchCannotBeStopped` asserts the Warn on a scripted watcher (see "Stop-failure
  Warn" below).
- **Docs.** `Run` says it returns after nats.go has closed the stopped watch's delivery, for at most 5 s after the
  watcher's own Stop returns, whether or not ctx has ended, that a stop failure is logged at Warn, and names this
  test as the library-claim evidence. The 5 s is spelled as a number in the exported doc; `watchOnce` (unexported)
  names `kvwatch.DrainBudget`. No exported signature changes or names `internal/kvwatch`.
- **Ledger.** The `internal/kvwatch` dependency in the `natsclient` ledger row is task 2.6, not done here.

## Uncovered

  same deferred stop but is not asserted for the Warn. No real-server failure of a watch's Stop is driven.

## Stop-failure Warn (review finding)

`Run` returns no error, so the Warn is the only report of a failed cleanup.
`TestReportConsumer_RunWarnsWhenTheWatchCannotBeStopped` (`storage_report_consumer_test.go`) goes through `NewConsumer`
and `Run` with `ConsumerConfig.Logger` writing to a buffer. `fakeKeyWatcher` gains `stopErr`, a sentinel `kvwatch.Stop`
does not treat as benign; its `Stop` still closes updates, so the drain ends at once. The test runs in a `synctest`
bubble: `synctest.Wait` then `watchCount() == 1` establishes the watch, the test cancels, and `<-done` (`Run` returned)
orders the read of the buffer after the deferred stop. No sleep, no production change.

Mutant: a copy of `storage_report_consumer.go` outside the tree whose deferred stop is `_ = kvwatch.Stop(ctx, watcher)`.
It builds; `slog` is still used by the file's other logging.
