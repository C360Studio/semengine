## Choices

- **graph-query's counts and summary stay on `prefix`** (design D2): their reads refuse on damage by ruling.
- **No enumeration token.** `prefixIDs` is not added to `composition/reserved_test.go`'s alphabet, because each token
  multiplies that check's run time about fivefold. `graph.ingest.query.prefixIDs` is still reached through
  `graph.ingest.query.entity`, since the two differ only in a last token outside the alphabet. The comment now says
  so.
- **The note on the graph-ingest handler map is gone.** It said the handler was not served until its row landed, and
  that stopped being true with this task.
- **`TestForwardPassesBytesBothWays` covers `prefixIDs`** through `forwardRows`, which also feeds
  `TestForwardsShareNothingBetweenRequests` and graph-query's declared-rows tests.
