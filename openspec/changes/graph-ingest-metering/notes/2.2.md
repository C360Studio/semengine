## Choices the design does not spell out

1. `recordMutationRejection` (`mutation_runtime.go:156` at the base) also goes. Its only caller was the inner wrapper;
   its counter increment and WARN now sit in `meteredCanonicalMutation`, the one metering layer, so the WARN can carry
   `detail`. The design's Removed list does not name it.
2. `detail` is logged with `slog.Any` only when the classified error's Detail map is non-empty; the text handler
   writes it as `detail=map[...]`. A classified error with an empty code still logs its Detail.
3. A reply that cannot be built returns `json.Marshal`'s error unchanged, as today. The wrapper counts it under
   `internal` on both counters, and the wire answer is unchanged (no code, class fatal). Classifying it with
   `rejectInternal` would change its wire class to transient, which the design does not declare. The path is not
   reachable from a request: each reply holds values the handler decoded from JSON or from a stored entity.
4. Append counts after `json.Marshal(response)` succeeds, one `recordCanonicalOutcome` per `response.Results` entry,
   taking `Error.Code` for a failed subject. The results are the handler's per-subject decisions, so the count needs
   no second list. `recordCanonicalOutcome` keeps its empty-label-to-`internal` rule, so a failed subject whose
   failure has no code counts under `internal`.
5. The removed WARN-2 test (`TestCanonicalMutationOutcomeMetricAndRevisionMismatchLog`) is covered by the
   reconcile row of `TestRefusedMutationMetersAndLogsOnce`, which asserts the outcome count and `expected_revision`
   in the one line.
6. `mutation_rejection_metric_test.go` wraps its fake handlers in a `canonicalMutationRoute` with operation
   `triple.append` and its own per-test subject; its tests are renamed `TestMeteredCanonicalMutation_*`.
   `structural_predicate_gate_test.go` takes the production route through `meteredRoute` (added in task 2.1). The
   comments in both, and in `structural_gate_wire_integration_test.go:26`, name the one wrapper.
7. The `graph-transport-boundary` MODIFIED delta was checked against the code and left as written: replies count once
   (`canonical_mutations.go` create, reconcile, delete) and an append once per subject; a refusal counts under its
   code or `internal`; the WARN carries the Detail; the authority WARN logs lane and segment index, not the identity.
