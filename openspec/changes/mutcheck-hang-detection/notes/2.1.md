# Task 2.1 notes

Choices the design leaves open, made while implementing task 2.1.

- **The logged-timeout recording prints with `os.Stdout.WriteString`, not `t.Log`.** Design D6 says the test
  `t.Log`s the panic text. `t.Log` prefixes the line with `hang_test.go:N:`, so the line does not begin with
  `panic: test timed out after` and the run's timeout fact stays false: the row would not reach the case D2 excludes
  (a test that reported a result after printing the panic text). Writing to standard output gives the line exactly
  as a test copying a child `go test`'s output prints it.
- **A third new recording, `hang-pass.jsonl`.** `TestReportDetectionByHang` drives the whole program with a stand-in
  `go`, so every run must name the same test. `pass.jsonl` names `TestValue`; `hang-pass.jsonl` is `TestHang` on the
  unchanged code, recorded by the same recipe rather than rewritten from `pass.jsonl`.
- **The elapsed time lives in `observed`, not `facts`.** `read` does not use it; only `decide` does, for a hang.
  "Not reported" is a separate `elapsedReported` flag, so it differs from zero (D1). The value is rounded to the
  millisecond `go test` prints.
- **The report line** is `wall time: <wall>; package elapsed time: <elapsed or "none reported">`.
- **D3's run count** is added to the "mutant runs disagree" reason only when fewer mutant runs were made than
  `-runs` asked for; a hang is the only early stop that can reach that reason, so other reasons are unchanged.
- **A control with no elapsed time** reads inconclusive with its own reason ("reported no elapsed time"), proven by
  the row "an after-run that reported no elapsed time".
- **Generated checks** are not used: the per-run reading is enumerated exhaustively (`TestReadEveryCombination`
  learns `hang`), and the cross-run rule is one comparison per control, proven by named rows at, over and missing
  the margin; examples suffice.
