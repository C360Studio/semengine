# Design: natsclient-contract

Status: revision 1, for pre-owner review. Issue #170; claim PR #177; base `0a4d6d5` (`main` `c713840`). It rests on
`inventory.md` revision 2. Inventory review r1 returned CHANGES REQUESTED with no BLOCKING finding. The owner's
time-box (relayed 2026-10-11) sends the fixes and this design to one review, without a second inventory review first.
That departs from architect contract step 3, and is recorded here for the owner.

## Context

Issue #170 asks for two things: a record of what natsclient promises over nats.go, each line measured, and a rule that
library claims cite a probe. The owner's constraints for this pass (2026-10-11): the record only takes promises away.
It adds no code, exported surface or mechanism; anything unmeasured is not promised; a spec that promises more is cut
to match. On `main` the inventory has 103 rows: 29 backed by a probe, 28 by tests only, 16 contradicted, 30
unmeasured. The five contradicted spec rows (M2, M6, M8, M11, M19) are all one class: a held write holds the call
past its context (P13, P14).

## Options

1. **Record and cut (recommended):** ADR-112, a delta that weakens four requirements, the rule. Cost: no bound on a
   call while a server stops reading, stated in ADR-112.
2. **Also correct the doc comments here:** a code pull request (Codex's review, Go `task verify`) on change 3's path.
3. **Make the promise true:** each of five ways adds mechanism (ADR-112, "Alternatives rejected"); ruled out.
4. **Do nothing:** the spec keeps a promise P13 and P14 contradict, and change 3 inherits it.

- **D3 (c): #168 is a documentation correction, not a code fix.** Under ADR-112 natsclient passes the held write

- **D4 (d): an in-tree test is a probe.** A test that drives the pinned library (embedded server, the `.nats-image`
  container, or real nats.go over a scripted connection) counts as a probe. It is the better form, because
  `task verify` re-runs it on every version bump. A test over a fake does not count. The other form is a program
  posted with its source, command, versions and output (`rule.md`).
- **D5 (e): no collision with `.agents/protocol.md:47-49`.** The rule binds statements a change adds or edits.
  Text carried unchanged from the pin stays under § Bounded port scope, which adds no experiment per finding. "Not
  promised" is always an alternative to a probe, so no finding forces an experiment.
