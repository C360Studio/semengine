# Task 4.3: T7, the client sentinels are transient

Choices the design (D5; "Tests that replace the probes", T7) does not spell out.

- **T7 lives in its own file**, `natsclient/client_sentinels_test.go`, one subtest per sentinel.
- **Expected values come from D5's table**, not from `pkg/errs`' code: both sentinels are transient, `ErrNotConnected`
  matches `errs.ErrConnectionLost`, and `ErrCircuitOpen` matches `errs.ErrCircuitOpen`.
- **`assert`, not `require`,** so one failing run shows every assertion that fails.
- **The `Classify` assertion passes on `main` too.** `Classify` calls an error it does not know transient by default
  (#167), so on `main` it already returns transient for both. It stays because the design's T7 says the two agree;
  `IsTransient` and `errors.Is` are what fail before the change.
- **No responders is not in T7** (design D5): it stays the raw `nats.ErrNoResponders`.
