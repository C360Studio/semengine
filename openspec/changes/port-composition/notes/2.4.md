## Choices the design does not spell out

- **The test loads through `LoadFromBytes`.** `LoadFile("../config/example_config.json")` is refused with "path
  traversal not allowed", since the test runs in `composition/`. `LoadFromBytes` merges the bytes with the same
  defaults and overrides `LoadFile` does (`config/config.go:398`).
- **The catalog is graph-ingest's `Register` alone,** the one factory the file names. It is called from a test file
  in `composition_test`, an external test package: no production import, no cycle, and `TestNoAggregatorPackage`
  reads only non-test files.
- **An empty composition cannot pass.** With no enabled component, `Validate` returns only an `empty_composition`
  warning. The test therefore also requires one graph node per enabled component, and at least one.
- **The example spells out graph-ingest's ports** (the same three it takes by default: `entity_stream`, `mutations`,
  `entity_states`) and its two other settings at their defaults, so a developer sees the full shape of a component
  entry. Without a `ports` key it would take the same defaults.
- **Platform, NATS and services blocks are unchanged,** as Q1 states, including the `mavlink-demo` platform id.
- **`TestLoader_ExampleConfig` now also calls `cfg.Validate()`**: the example must pass the loader's own check, not
  only composition's.
- **No other document cites the old example's components.** `git grep -n example_config` outside `openspec/` finds
  only `config/config_test.go`; `config/README.md`'s `udp-mavlink` block is its own inline example, not this file.

## Warnings the clean result carries

All four come from graph-ingest standing alone, with nothing publishing to it or reading from it. A deployment of
this file runs: entity messages arrive from producers outside the composition, and products call the mutation and
query subjects directly.

- `disconnected_node` on `graph-ingest`: no edge to another component, since there is no other component.
- `orphaned_port` `entity_stream` (`no_publishers`): no component in the file publishes to `entity.>`.
- `orphaned_port` `mutations` (`optional_api_unused`): no component in the file calls `graph.mutation.>`.
- `orphaned_port` `entity_states` (`optional_index_unwatched`): no component in the file watches `ENTITY_STATES`.

None is an error: `severityOf` makes an orphan an error only for a required stream input, and `entity_stream` is not
required.
