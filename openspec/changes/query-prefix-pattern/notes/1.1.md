## Generated / Example Check Rationale

- Exact 6-position entity-ID pattern validation and matching (`ValidateEntityIDPattern` and `MatchEntityIDPattern`) are
  already covered by Rapid property tests in `pkg/types/entity_id_prop_test.go`. Handler-level wiring in
  `processor/graph-ingest` is a deterministic 3-branch dispatch (`Prefix != "" && Pattern != ""`, `Pattern != ""`,
  `Pattern == ""`) over those primitives, so table-driven unit tests (`TestQueryPrefix_PatternInvalid`,
  `TestQueryPrefix_PatternMatchesAcrossSystems`, `TestQueryPrefix_PatternCursorPaging`, `TestQueryPrefix_PatternNoMatches`)
  and the real NATS KV integration test (`TestIntegration_PrefixQuery_PatternAcrossSystems`) suffice.
