## Mutant 1 again: a test that holds a health callback open (detected)

Added after Codex's code review on PR #421 (MEDIUM: Stop's wait for an in-progress health callback was not tested
deterministically). `TestComponentManagerStopWaitsForInProgressHealthCallback` in
`service/component_manager_supervisor_test.go` composes one component whose `Health()` signals its first call and
then waits on a channel the test owns. The test starts the manager and waits for that signal. It then launches `Stop`
in a goroutine, settles the bubble with `synctest.Wait`, and requires that `Stop` has not returned (`:98`). Then it
releases the callback and requires that `Stop` returns nil. A `t.Cleanup` releases the callback and stops the
manager, so a failed assertion does not leave the bubble deadlocked. The test uses `synctest` because the NATS client is
unconnected (`newUnconnectedClient`), so no nats.go connection runs in the bubble (#156). No production code changed.

The run is on commit `4685e0f20bc1e11378872ce371378501d5d9b9df` with the new test uncommitted (report: `tree:
52b7fb1f6401 before the first run, 52b7fb1f6401 after the last; uncommitted changes: yes`). The mutant is the same
wrong change at `service/component_manager_lifecycle.go:215`, kept in `/tmp/mut362b.VReo/m1.go` (on this machine
only). Defaults as above. All three baseline runs and the after-run passed.

```text
task mutate:check -- -pkg ./service -test TestComponentManagerStopWaitsForInProgressHealthCallback \
  -file service/component_manager_lifecycle.go -mutant /tmp/mut362b.VReo/m1.go \
  -expect component_manager_supervisor_test.go:98
```

Result: `verdict: detection: each of the 3 mutant runs failed the named test with an expected line, and the
after-run passed`. Detected by `TestComponentManagerStopWaitsForInProgressHealthCallback` at
`service/component_manager_supervisor_test.go:98`. This detection does not depend on scheduling: `synctest.Wait`
returns only once every goroutine in the bubble is blocked, and the callback stays blocked until the test releases it.
