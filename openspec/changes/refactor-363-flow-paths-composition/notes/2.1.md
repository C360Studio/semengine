# Task 2.1 notes: `TestFlowPathsRouteServesTheLibraryAnswer`

## Choices the design leaves open

- The test asks the route through `RegisterHTTPHandlers("/components/", mux)` and `GET /components/paths`, so it
  covers the mounted route, not only the handler function.
- Composition: two origins of type `input` (each with a timer input, like `poller` in
  `TestFlowPathsTraverseTheRetainedGraph`). `long` publishes `paths.route.raw` to `relay`, which publishes
  `paths.route.done` to `sink`; `short` publishes `paths.route.done` straight to `sink`.
- Hand-written expected values: `paths` = `long: [long relay sink]`, `short: [short sink]`; `input_component_count` 2
  (two origins), `max_path_length` 3, `total_reachable` 5 (3 + 2), `avg_path_length` 2.5 (5 / 2).
- `statistics` is decoded into `map[string]float64`, since JSON numbers decode as float64. 2.5 is exact in a float64,
  so the average is compared exactly, with no tolerance. Two origins were chosen over three for that reason: lengths
  3, 2, 2 give 7/3, which a float64 does not hold exactly.
- `timestamp` is checked only by `time.Parse(time.RFC3339, ...)`; its value is not compared.
