## Choices the design leaves open

- `Len` reads an atomic count kept beside the map and written under the lock, so the graph-ingest fast path
  (`poison_inventory.go`, one atomic load when nothing is recorded) keeps its cost by calling `Len() == 0`.
- A report at the recorded revision replaces the refusal (returns false), as both current records do.
- `Entry` carries its `Key`, so `Sorted` returns entries a caller can render without a second lookup.
- `Sorted` copies under the lock and sorts after releasing it.
- `TestConcurrentReportsAndClears` is added beside the named cases because D3 states the type is safe for
  concurrent use; no exported surface beyond D3.
