## `netDial`'s comment

The task rewrites it only if it names a removed hook or `connectWith`; it names neither. It is rewritten anyway
(`client.go:100`-`:103`) because it was no longer complete: it said a test replaces `netDial` only to hold a dial open,
and since task 2.3 `connectScripted` replaces it to hand over a pipe (`notes/2.3.md`, "Left for later tasks"). The new
comment names both uses, taken from the design's Recommendation table (rows 1, 11, 13 hold a dial; rows 18-24 hand
over the pipe) and from the reason `subscribe_registration_test.go:29`-`:31` gives for the pipe. The label `T4` stays:
it is ADR-112's name for `TestConnectEndsWithItsContext` (`docs/adr/112-natsclient-contract.md:43`), whose
"deadline while dialling" case holds a dial open.

## The check

- On the whole tree, the first `git grep` prints twelve lines, all in `metric/handler.go` and
  `metric/lifecycle_test.go`: `metric.Server`'s own `opHook` and `recordOp`. They are issue #207, outside this change,
  and are left alone. Limited to `natsclient/`, both `git grep`s print nothing. The check as written cannot print
  nothing until #207 lands, or until its paths are limited to `natsclient/`.
- `\b` matches nothing in `git grep -E` on Apple Git 2.50.1: `git grep -n -E 'netDial\b' -- natsclient/client.go`
  prints nothing although `netDial` is at `client.go:100`. So the second check's `nativeSubscribe\b` alternative
  cannot match on that git. `git grep -n -E 'nativeSubscribe' -- '*.go'` prints nothing; without `\b`, the pattern
  still does not match `nativeSubscription`.
