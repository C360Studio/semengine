## base.go (D1, D2)

- Removed: `ErrAlreadyStopped` (S5), `validateLifecycleContext`, the `config` import and field (Q1), the three
  options, `OnHealthChange` (method and field), `RegisterMetrics` (method and `Service` entry), `contextMonitor`,
  `performGracefulShutdown`, and the `cancel`/`done`/`wg`/`healthTicker`/`healthInterval` fields. "semstreams
  platform" in the package comment is "SemEngine".
- Mechanism, as the design recommends: `BaseService` composes `internal/lifecycleguard.Guard`. `Start` is
  `lifecycle.Start(ctx, s.start, s.stop)` and `Stop` is `lifecycle.Stop(ctx)`, so the refusals (nil, ended, second
  Start, Start after Stop) and the ended-context Stop are the guard's. `start` cannot fail, so the guard's rollback
  never runs. It creates the run context as `config.Manager` does,
  `context.WithCancel(context.WithoutCancel(ctx))`, and keeps only its cancel (ADR-113). `stop` reports
  `StatusStopping`, cancels, waits for `healthDone` under Stop's context, and only then clears the handles, stores
  unhealthy and reports `StatusStopped`; a Stop whose context ends while it waits returns that error and leaves the
  handles, so the guard's next Stop runs `stop` again and waits again.
- The health interval is a package constant, `healthCheckInterval = 30 * time.Second`, since no option sets it now.
  The ticker is made and stopped inside the health goroutine.
- Status changes go through one helper, `setStatus`, which stores the status and records it with
  `CoreMetrics().RecordServiceStatus` on the injected registry, at the same points the pin recorded it.
- Kept as at the pin: `Health()` (its `RLock` included), `GetStatus`, `SetHealthCheck`, `performHealthCheck` (less
  the callback), and the `logger`, `messagesProcessed` and `lastActivity` fields. Nothing in PR 1 reads `logger` or
  writes `messagesProcessed`; the component manager reads `BaseService.logger` (pin `component_manager.go:1209`,
  PR 3).
- `Service.Stop`'s doc says a Stop after one that returned nil returns nil (Q2), and no longer names gh#520 or
  `ErrAlreadyStopped`.
- Generated checks: the guard is composed, so the design's examples suffice (design, Generated checks); no history
  check is added.

## pprof.go (D3)

- `MaybeStartPProf(debug, port, logger)` returns nil when disabled; otherwise it binds `:port` with `net.Listen`
  before it returns. A bind failure is logged at Warn, `"pprof server not started: bind failed"` with `port` and
  `error` attributes, and returns nil. A successful bind is logged at Info with the bound address, in place of the
  pin's `fmt.Printf("Starting pprof server on %s\n")`.
- `startPProf(server *http.Server, listener net.Listener) *PProfServer` is the design's seam; the pin's `listen`
  function is gone. The serving goroutine records any `Serve` error other than `http.ErrServerClosed` and closes
  `done`.
- `Shutdown(ctx)`: a nil context is refused with `errs.WrapInvalid(errs.ErrInvalidData, ...)` before the nil-server
  check. Then `http.Server.Shutdown(ctx)`; its error (the context's, when a request is still in flight, probe H2) is
  returned as is. After it returns nil, Shutdown waits for `done` under `ctx` and returns the recorded serve error.
  A later Shutdown calls `http.Server.Shutdown` again, which waits again (probe H4).
- The doc comment keeps ADR-058 step 4's "not a service.Service, called early" and the caller's blank import, and
  drops "Fire-and-forget" and "process exit cleans the listener": the composition root calls Shutdown.
