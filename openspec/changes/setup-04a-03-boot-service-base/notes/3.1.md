## ADR-058

- `docs/adr/058-boot-lifecycle-phases.md` is the pin's file with a port note under the title, in the shape of
  ADR-102's. The text below the note is the pin's except for three bold labels under Consequences (`**Positive**`,
  `**Negative / cost**`, `**Neutral**`), made `###` headings because markdownlint refuses emphasis used as a heading
  (MD036).
- **The design names a phrase ADR-058 does not contain.** The design's Decision records say the port note records
  ADR-058's "Terminal shutdown remains Start-owned" as superseded by ADR-113. That phrase is in pin ADR-094
  (`094:44`), which the inventory cites correctly (`inventory.md:421-422`) and ADR-113 already supersedes
  (`docs/adr/113-start-context-bounds-start.md:123`); `grep` of pin `058` finds no "Start-owned". What ADR-058 does
  have is the same rule in its worked example: `OwnershipService.Start` derives its run context from the Start
  context (`058:232`). The port note records that as superseded by ADR-113. The design text is the architect's and
  is not edited here.
- The note also names `service.ConfigureRulePackMutations`, which the pin's Status amendment calls "the live
  composition helper", among the names not ported.
