### Choices the design leaves open

- **Names the tests call.** `Metrics` keeps the embedded `*BaseService` and the fields `config`, `server`
  (`*metric.Server`, D4 S10) and `testListener`; `claimManagerServer() (*metric.Server, error)` as at the pin.
  The `/graph/triples` scan is `scanGraphTriples(ctx, reader kvcatalog.CatalogReader, params tripleQueryParams,
  logger *slog.Logger) ([]message.Triple, error)`: it returns `[]`, never nil, on success and nil on error; the
  `Manager`'s query opens the reader and calls it. The pin's `graphTripleKeys`, `graphTripleEntry`,
  `parseTripleQueryParams`, `tripleMatchesQuery` and `serveGraphTriples` keep their signatures (carried tests).
  The 400 for a malformed `subject` or `predicate` is proven through `serveGraphTriples`, so it may sit in
  `parseTripleQueryParams` or the handler.
- **Metrics pin tests.** `TestMetricsStopRunsProviderOutsideLockAndRejectsConcurrentStop` becomes
  `TestMetricsStopRejectsConcurrentStop` on the real server: a collector that blocks holds a scrape in flight, two
  Stops race, the refused one returns first (transient), the other returns nil after the scrape. The pin's fake
  provider went with `metricsServer` (S10). `TestMetricsRollsBackBoundProviderWhenBaseCommitFails` becomes
  `TestMetricsRollsBackItsServerWhenBaseServiceStartFails`, built through `NewMetrics` (the base service is stopped
  first, so its Start is refused). `TestMetricsLifecycleContextAndStopBeforeStartAreImmutable` keeps its name and
  reads what a caller sees instead of the private `used` flag. Not carried:
  `TestMetricsFailedStartCleanupRetainsAuthorityUntilSuccessfulStop` (needs the fake provider's failing Stop; the
  retained cleanup is the guard's, proven by `internal/lifecycleguard`'s tests) and
  `TestMetricsStopWaitsForStartFinalizationBeforeProviderCleanup` (drives the three test hooks that go with the
  copied machine, S9; Stop waiting for Start is the guard's).
- **Suite adapter.** `metricsOwner.Observe` lists `metrics-server` while `m.server` is set and `health-loop` while
  the base service's health goroutine runs. It reads `m.server` without Metrics' lock: the suite observes only after
  the call it judges returned, and the health goroutine only reads the field. It does not dial the listener: a
  `testListener` never handed to a server stays open, which a Stop before Start would then report as held.
  `mustFail` and `TestMetricsStartReportsServerBindFailureBeforeReturning` hold their port on `:0`, every interface,
  as `TestMaybeStartPProfLogsABindFailure` does (probe H1 on #343).
- **`TestServiceConfigRefusesKeyInAnotherCase`** sits in `metrics_config_test.go`. The metrics payload goes through
  `NewMetrics` (the spec's literal); the manager's payload goes through `decodeStrictServiceJSON` with
  `ManagerConfig`, top-level `HTTP_PORT` and nested `server_info.Title`, each beside its exact spelling, which
  decodes. That the manager's own decode calls `decodeStrictServiceJSON` is D2's, for part 3. The expected text
  assumes `decodeStrictServiceJSON` passes the path `""` to `keycase.Check`.
- **`TestTypeNameFromReflectNamesEachShapeApart`** sits in `schema_test.go`, beside `TestTypeNameFromReflect`,
  whose assertion that `[]int` is named `"[]int"` is removed: it pinned the behaviour #349 fixes, and `[]int` does
  not match `^[A-Za-z0-9._-]+$`.
- **`TestScanGraphTriplesMatchesSortedOracle`** (Generated checks) has a named example first, keys listed in
  reverse with limits 1 and 3, so the unsorted-scan mutant fails on every run, not only on a lucky draw. The
  generated part: zero to six entities from a six-ID pool, zero to three triples each from two predicates and
  objects `"x"`, `"y"`, `2.0`, listed in a drawn permutation; each filter absent or one pool value; the limit drawn
  from 1, matches-1, matches, matches+1. The oracle sorts the IDs itself and matches each filter on its own; results
  compare as JSON, since the scan reads triples back through the codec. Seed and completed-check count are recorded
  when the test first runs (task 2.2); nothing runs on this commit.
- **`TestGraphTriplesSkipsOnlyADeletedKey`** also covers an entity `graph.UnmarshalEntityState` refuses (500), the
  spec's other 500 case, and asserts the 500 through `serveGraphTriples` with the scan as its query.
- **`registry_race_test.go`.** `TestServiceManager_ConcurrentOperations` checks each registered name through
  `Registry.Constructor` (the pin counted the dropped `Constructors`); `TestServiceManager_ErrorHandling` loses its
  `GetServiceStatus` line (dropped). `mockService.RegisterMetrics` is not carried (no such interface method or
  `metric.MetricsRegistrar` here). The pin's `mockService.GetStatus` called `Status` while holding the read lock, a
  recursive `RLock` that deadlocks when a writer waits between them; it now calls an unlocked `status`.
- **`register_test.go`** also asserts `RegisterAll` offers `metrics`, so the absence checks cannot pass on an empty
  registry.
