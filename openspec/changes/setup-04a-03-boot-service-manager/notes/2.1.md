# Notes: task 2.1 (tests first) — partial, not committed

Status: in progress. Done so far: the `internal/keycase` and `internal/httpadmission` tests and the test-side
edits in `config` and `metric`. Not started: the `service` tests (D7's table, the two suite adapters, D2-D6's new
tests).

## Choices the design leaves open

- `metric/admission_test.go` is split, not moved whole. `TestServerRefusesRequestAfterStopReportedCompletion`
  drives `metric.Server` through `metric`'s own test helpers (`boundServerListener`, `newExitingCollector`), so it
  stays in `metric` as the proof that `metric`'s behaviour is unchanged (design D2). The counter's own test,
  `TestAdmittedRequestsRefuseAfterClose`, moves to `internal/httpadmission/admission_test.go` as
  `TestRequestsRefuseAfterClose`, now also asserting the caller's refusal text, with a new
  `TestRequestsWaitForAnAdmittedRequest`.
- `internal/httpadmission`'s surface, as the tests call it: `type Requests` (zero value ready),
  `Wrap(next http.Handler, refusal string) http.Handler`, `CloseAdmission()`, `Pending() int`,
  `Wait(ctx) error`. The refusal text is a `Wrap` argument so the zero value stays usable, as `metric`'s
  `&admittedRequests{}` is today.
- `internal/keycase`: `keycase_test.go` holds one case per shape the walk visits (design § Generated checks), and
  `guard_test.go` the moved guard (`TestPayloadTypesReachOnlyShapesTheLetterCaseCheckWalks` over `config.Config`,
  `service.ManagerConfig`, `service.MetricsConfig`) with `TestLetterCaseWalkerGapsDetectsEachShape` and its helper,
  removed from `config/load_test.go` (the `types` import went with them).
