## Partial-subscription rollback (decided)

Design D8, S12: the three tests of `failed_start_subscription_test.go` should "fail a real subscription instead" of
the removed hook. `SubscribeForRequests` fails only when the client is closing, Start's context has ended, or the
connection is down (`natsclient/client.go`, `subscribeOwned`). `start` checks its context after opening the buckets,
and the subscriptions come next, so each real trigger needs the context or the connection to end between two
subscriptions: a timing the test cannot choose without a hook (#186). No deterministic trigger was found. Choices for
the orchestrator: (a) drop the three, recording the partial-subscription rollback as uncovered (review checks that
`cleanup` drains `c.subscriptions` and that `subscribeQueries` records each as it is made); or (b) name a trigger.

Orchestrator decision (2026-10-27): (a). The three tests are dropped and the partial-subscription rollback is an
