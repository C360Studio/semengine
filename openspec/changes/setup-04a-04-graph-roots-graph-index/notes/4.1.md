## Configuration

- Kept the pin's port merge: a `ports` block with an empty `inputs` or `outputs` list takes the default list for that
  side (`pin:processor/graph-index/component.go:132-175`). Ruling K (#91 comment 6062681355, "a present block is
  used as written, with no merge") was ruled for graph-ingest (#139); the design does not extend it to graph-index,
  so Bounded port scope keeps the pin's behaviour. Open question for the orchestrator.
- Strict-decode and port-resolve errors are classified invalid (`errs.WrapInvalid`); the pin wrapped the unmarshal
  error unclassified. A configuration the factory refuses is invalid configuration whatever the cause.
- `coalesce_ms`, `startup_attempts` and `startup_interval_ms` are not range-checked, as at the pin.
- `maxGraphIndexWorkers` is renamed `maxWorkers` (the package name already says graph-index).

## Metrics

- `key = readiness.KeyGraphIndex` names the registration, the logger, the metric service of every
  `metric.RegisterOrGet` call, and (task 4.3) the follower's `Config.Key`. The subsystem is
  `strings.ReplaceAll(key, "-", "_")`, the same expression `graph/follower/follower.go:161` uses for the readiness
  gauges. That is the derivation written twice; a `readiness` helper would make it one, but it adds an export to
  approved code stop 1, so it is left as an open question rather than done here.
- Seven collectors, the pin's names with namespace `semengine`; the readiness gauges are the follower's (D10). A
  `RegisterOrGet` error fails construction; the pin discarded registration errors.
- Only the two record helpers with logic are ported (`recordReindex`, `recordReconcileOperation`). The pin's other
  five were one-line `Inc` wrappers; task 4.2 writes to the collectors at its call sites or adds a helper as it
  needs one.
- `watch_events_total{event_type}` stays: task 4.2's `Deliver` sees `Entry.Deleted` and can record update or delete.
- The guard named for this task, "the metric-registry guard in `task lint`", is `TestNoProcessGlobalRegistration`
  in `internal/harness/contract/promglobal_test.go`, which `task test:unit` runs; `task lint` has no metric guard.
