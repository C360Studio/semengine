## Choices the design leaves open

1. **The resolver takes the alias request's bytes.** `entityByAlias` still sends the caller's bytes unchanged
   (`testEntityByAliasKeepsEntityJSON`); global search builds `{"alias":<reference>,"min_revision":n}`, the
   `min_revision` omitted when 0. So the resolver takes the request bytes and the reference beside them.
2. **What falls through.** Only `entity_not_found` from the entity verb (the entity read, or `readPathStart` for a
   path) becomes `text_search_unsupported`. The same code from the alias verb passes through, as every alias refusal
   does (`TestForwardedRefusalKeepsClassCodeDetail`'s `globalSearch` row sends it).
3. **What counts as an error.** A route refusal coded `internal` (an ended classification, a hint that cannot be
   read) counts one error in the handler; the two filters, the impossible number and `text_search_unsupported` count
   none. Downstream errors are counted where step 2 counts them (`ask`, `brokenReply`), so each request stays one
   input and at most one error.
4. **An empty entity reply is refused.** `GlobalSearchData.Entity` is `omitempty`, so an empty entity reply would
   have answered `{"strategy":"entity"}` with no entity. It is refused transient `internal` naming the entity verb, one
   error (the counting test's "an empty entity reply" step). `entityByAlias` refuses the same reply through the marshal.
5. **The path answer is built as `pathSearch` builds it:** `readPathStart`, then `walkPaths` with `indexHop` carrying
   `min_revision`, enveloped under the walk's revision. The alias reply's revision is not used for `path`.
6. **Temporal and spatial until task 3.3.** The route reaches them; the handler refuses transient `internal` ("the
   temporal strategy is not built yet") and counts one error, marked `// shortcut:` at the site. Task 3.3 replaces it
   in this pull request; no test asserts the placeholder.
7. **The ended classification through the handler** is shown in the unit test (`TestGlobalSearchEndedClassification`):
   the production handler from `queryHandlers()`, called under an ended context as natsclient calls it once the
   handler budget ends. No connection is needed: the refusal comes before any request.
