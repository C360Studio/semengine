## Choices the design leaves open

1. **Surface.** `New(suffixes, maxLen) Rule`; `Rule.Values`; `Rule.Document(state, body) Document` with `Name`,
   `Body`, `Cut`; `ReadBody(ctx, Stores, message.StorageReference, maxLen)`; `Stores` (the one-method registry
   interface `*storeregistry.Registry` and graph/embedding's `StoreResolver` both satisfy); `ErrNoStore`;
   `DefaultSuffixes()`; `Truncate`. Beyond the symbols the design names, `Truncate` is exported because the Worker
   cuts with it, so the cap has one routine (graph/embedding's `truncateAtWord` now calls it, and its existing tests
   keep running through that name); `Stores`, `ErrNoStore` and `New` are the spec's store registry, "no store" error
   and empty-suffix default. For the reviewer's exported-surface check.
2. **Label predicates** are read once in `New` (`vocabulary.DiscoverLabelPredicates`) and matched on the exact
   predicate, as graph-index's name index reads them (`processor/graph-index/index.go:88`, `:324`), so an entity
   `byName` finds is found by the same predicates' words.
3. **"Each once"** is read per triple: a value whose predicate is a label and ends in `.title` (`dc.terms.title`) is
   in Name once. Two triples with the same string are both kept, as `Values` keeps them.
4. **Joins.** Name and Body are joined with one space, and the offloaded body follows the inline body after one
   space. `Values` keeps graph-embedding's one-space join in `extractText`.
5. **`ReadBody` does not cut.** It reads `maxLen*utf8.UTFMax+1` bytes and returns them; the caller cuts. The Worker
   keeps its own cut sequence (body, then identity plus body), so its bytes and truncation counts are unchanged;
   `Document` cuts its Body.
6. **A caller's cancel is not a deadline.** When the read's context has ended, the error wraps that context's error:
   `context.DeadlineExceeded` at the 10 s deadline, `context.Canceled` when the caller's context was cancelled. The
   Worker's shutdown rule (`markFailed`: a cancel while its context has ended is not a failure) is unchanged.
7. **A cap below 1** is refused by `ReadBody` rather than read without a bound.
8. **One "no store" spelling.** graph/embedding's `errContentUnresolved` is removed; the Worker matches
   `entitytext.ErrNoStore`.
9. **The zero `Rule` selects nothing**; the doc comment says to build one with `New`.
10. **Docs made false by this change.** `processor/graph-embedding/README.md`'s known limit "Offloaded-body fetch
    has no deadline" is replaced with the 10 s bound; the admission ledger's `graph/embedding` and
    `processor/graph-embedding` rows gain `graph/entitytext` and the new behaviour. Task 3.1's README additions are
    left to it.

## Generated checks

Not used. `Values` and `Document` decide each triple on its own (relationship, string, suffix, label); the only
interaction is order and the one cap, and the named cases cover each class: label only, suffix only, both,
neither, relationship, non-string, empty, case, and the cap under, at and over the limit, in characters not bytes.
There is no order-dependent history in this task. `Truncate` is moved unchanged and keeps graph/embedding's
existing tests (`truncate_test.go`, `truncate_runesafe_test.go`). No new surface parses a grammar, so no fuzz
target.
