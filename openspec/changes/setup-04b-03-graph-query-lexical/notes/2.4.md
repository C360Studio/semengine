# Task 2.4 notes: the router (PR B)

Base commit `041bd512`.

## What changed

`globalSearch` and `searchGraph` (`processor/graph-query/globalsearch.go`) answer every question that decodes with
2.3's word search and batch read (`globalText`), then verify the route's reference, then list the hints. The old
router's strategies (entity, path, temporal, spatial, text), `chooseRoute`, `twoFilters`, `globalEntity`,
`globalPath`, `globalTemporal`, `globalSpatial`, `truncatedAbsent`, `isEntityNotFound` and `globalIndexLimit` are
deleted, and global search no longer reads the time-range or bounds subjects. `GlobalSearchData` is `text`,
`entity`, `path`, `hints`; `TextSearchData` loses `unhonoured_hints`; the new `graph.GlobalSearchHint` is the list's
element (`hint`, `detail`, `honoured`, `reason`, `code`). This retires 2.3's leftovers: `unhonoured_hints`, the
path-question bound in `TestSearchRequestsAreBounded`, and "no other request" for one-word questions
(`TestGlobalSearchPassesWordIndexRefusals` now asks `pump*` too and spies on the batch, alias and entity verbs).

## Choices the design leaves open

- **Order: classify, word search, batch, verify.** Classifying makes no request, so it comes first; a
  classification that cannot be read (ended context, unknown hint shape) is still transient internal with one
  error, which keeps `TestGlobalSearchEndedClassification` unchanged as the task asks. The word search and batch
  come before any hint read, so a refusal of either is the reply and no hint is read.
- **The hint element is `graph.GlobalSearchHint`.** `detail` and `reason`/`code` are omitted when empty;
  `honoured` is always sent. Details: the reference or start; the time range as two RFC 3339 times joined by " to ";
  the area as `north N, south S, east E, west W`; the aggregation as `max of temperature` or `count`; the
  classifier refusal's text. Similarity and ranking carry no detail.
- **Reasons** for hints never honoured are fixed sentences (`reasonTimeRange` and the rest in `globalsearch.go`).
  A verified hint that fails carries the refusal's message as `reason` and its code as `code` (`internal` when the
  failure is graph-query's own, such as no responder). A classifier refusal is `code` `invalid_request`.
- **Order of the list**: the verified hint (entity or path) first, then path-without-start, time range, area,
  aggregation, similarity, ranking, or the one classification hint.
- **A start beside path predicates** (another classifier's options; the keyword classifier sends none) is not
  verified: it is a `path` hint not honoured, since the walk follows every predicate.
- **Entity bytes that are not JSON** (or empty) are graph-query's broken reply, one error, and the hint is not
  honoured: the bytes go into the reply as they came, and would break it.
- **Errors in Health**: a hint read that fails on graph-query's side counts its one error where it is found, as
  before, while the reply still answers. A request whose hint read fails that way and whose matches also hold an
  unreadable group record counts two; no test drives both at once.
- **The reply's revision** is the word search's; the hint reads' revisions are not reported.

## Tests

New: `TestEveryQuestionIsSearched`, `TestWordIndexRefusalComesFirst`, `TestVerifiedStartAddsAWalk` (was
`TestGlobalSearchPath`), `TestUnverifiedStartIsReported`, `TestZoneQuestionIsSearched` (was
`TestZoneQuestionNeverAnswersEmpty`), `TestClassifierRefusalIsAHint` (unit; absorbs
`TestGlobalSearchRefusesImpossibleNumbers` and the two-places cases of `TestGlobalSearchRefusesADroppedPlace`),
`TestGlobalSearchListsHints` (unit; was `TestGlobalSearchRoutesByHints`, and absorbs the questions of
`TestGlobalSearchHintBesideAFilter` and `TestGlobalSearchRefusesTwoFilters`, now each listed hints).
`TestGlobalSearchEndedClassification` is unchanged, byte for byte.

Deleted with the behaviour they proved: `TestGlobalSearchTemporal`, `TestGlobalSearchSpatial`,
`TestGlobalSearchNoResponders`, `TestGlobalSearchRefusesADroppedPlace` (the zone-alone walks it checked are path
hints now, proven by `TestVerifiedStartAddsAWalk`), `TestGlobalSearchTextQuestion` (covered by
`TestEveryQuestionIsSearched`), and their helpers.

Changed to the new reply: `TestGlobalSearchEntity`, `TestGlobalSearchOneWordIsAReference`,
`TestGlobalSearchPassesAliasRefusals` (each refusal is the hint's code and reason; the reply answers),
`TestGlobalSearchUnknownWordIsSearched`, `TestGlobalSearchUnknownIDIsSearched`, `TestGlobalSearchUnknownPathStart`
(the holder-gone case; the `pump-99` case is `TestUnverifiedStartIsReported`), `TestSearchGraphAnswersAsGlobalSearch`
(a missing start and a time range now answer), `TestComposedVerbsCountAsForwardsDo` (the hint steps run beside a
readable record, so only a hint read's own failure counts), `TestMinRevisionRefusalThroughGraphQuery` (the word
search refuses first whatever the hints), `TestGlobalSearchTypesWire`, `FuzzDecodeGlobalSearchRequest` (routing
never refuses under a live context; every listed hint is known, not honoured, with a reason). Smoke reads `text`
without `strategy`; 2.6 owns the rest.

The expected hints in `TestEveryQuestionIsSearched` are the archived router probe's routes and refusals
(`openspec/changes/archive/2026-11-12-setup-04b-01-lexical-index/notes/probes/router-probe.log`) written out by hand:
a route `path X` is a `path` hint `X` with `entity_not_found`, `not honoured: Y` is a `Y` hint, a refused
aggregation is an `aggregation` hint with its operation, `temporal` is `time_range`. "mean time between failures"
also lists the path word "between", which the probe never showed because the aggregation refusal came first.

## Generated checks or examples

Routing is a fixed mapping from the classifier's options to a list; named examples cover each hint kind, each
combination the old router refused, the one-word rule and both classifier refusals. The fuzz target holds the
routing laws over any accepted request; seed replay passes in `task test:unit`.

## Not covered

- No test drives a hint read that fails on graph-query's side beside an unreadable group record (two errors).
- The time range and area details are checked for shape, not for the classifier's exact values.
