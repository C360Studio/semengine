Choices the design does not spell out:

- The watch test queues a valid entry after the refused one. For the misfiled value, today's watch skips it (the
  phase triple names the other entity), so without the follow-up entry the base run would block and synctest would
  report a deadlock instead of an assertion failure. With it, the base run delivers the later entry and fails on
  the assertions above.
- The watch and reconcile tests encode the stored value with `json.Marshal`, not `graph.MarshalEntityState`: the value
  is one a writer outside graph-ingest could store, and the encoder's checks are not under test.
- The one-layer check on today's `UnmarshalEntityState` (`TestUnmarshalEntityStateRefusalIsClassifiedOnce`) is a base
  API stand-in. Task 2.2's table asserts one layer on every row with the new signature and replaces it.
- The independent oracle is the spec delta's text: the reason, the entity (the key), the code and the one layer are
  written in the test from "One rule decodes a stored entity", never read from the decoder.
