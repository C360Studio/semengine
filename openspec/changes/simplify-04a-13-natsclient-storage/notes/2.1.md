Choices the design does not spell out:

- **Departure: two assertions on natsclient's private state are dropped.**
  `TestIntegration_StorageInventory_EnumeratesTheAccountNotTheClient` read `observer.jsMetrics.mu` and
  `observer.jsMetrics.streams` (natsclient's unexported tracked-stream map) twice: a premise check that the fresh
  client tracks no stream, and the subtest "the tracked-stream view still cannot see them". A test in another package
  cannot read unexported fields, and natsclient offers no exported read of that map; adding one would be a back door.
  Both reads are removed and the doc comment now says what the test still proves: the collector's only path to the
  account is `AccountStreamLister(client)`, and storagereport cannot reach the tracked-stream map, so a client-touched
  view cannot have produced the resources. Every other subtest is unchanged. The design (D2) said the moved tests are
  edited only for the package clause, qualifiers and the D1 names; this is the one exception, raised to the caller for
  a ruling.
- The integration fixture is `natsclient/storagereport/fixture_integration_test.go`: `TestMain` with
  `natsfixture.Shared`, and copies of the four natsclient helpers the test uses (`startFixture`, `failureBound`,
  `stopBound`, `closeClient`), plus `closeBudget`, which `closeClient` needs (natsclient keeps it in a unit test file).
  The `// Own server:` comment stays above `natsfixture.New`.
- The storage rows of `nil_context_siblings_test.go` move to `natsclient/storagereport/nil_context_siblings_test.go`,
  in a test with the same function name, `TestExportedNilContextRefusedOnEveryOtherEntry`, so a citation by name finds
  both halves. It needs no server: the collector and publisher are built on the fakes the moved unit tests use. The
  row for the publisher is now named `Publisher.Publish`.
- Two comments that name an old path (`storage_report.go:11`, `kvcatalog_storage_report_test.go:51`) are left for
  task 3.5, which lists them.

**Orchestrator ruling (2026-10-16):** the departure is accepted. The two removed reads guarded against the collector
enumerating through natsclient's tracked-stream map. After the move the compiler forbids that path: `storagereport`
cannot reach the unexported map, and its only route to the account is `AccountStreamLister`. The subtests that the
collector sees streams this client never touched still carry the behaviour. No natsclient-side test is kept, because it
would test natsclient internals this change does not touch.
