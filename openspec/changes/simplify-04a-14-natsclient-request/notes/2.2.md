## Choices the design does not spell out

- The handler-run count is read after the call returns. Every attempt the call makes is answered before it returns,
  and the handler counts before it replies, so the count is final at that point; no wait is needed.
- The headers test's handler returns `errs.ClassifiedCode(errs.ErrorInvalid, "entity_not_found", …)`, so the expected
  class and code are written in the test, not derived from natsclient.
