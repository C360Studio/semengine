# Task 3.1 notes

Base: `567a319`, production code in `graph/readiness` unchanged by this task.

## The tests

- `TestReadingZeroValueFailsClosed` (`readiness_gate_test.go`) replaces `TestStatusReading_ZeroValueFailsClosed`. It
  asserts the zero `Reading` gives `status_unknown`, and that the in-process shape `Reading{Status: s, Fresh: true}`
  (no `Known`, `Age`, `Raw` or `Err`) proceeds on a healthy envelope.
- `TestDeferReasonsReturnsACopy` compares `DeferReasons()` with the four label strings the spec delta names, written
  as literals rather than the package's constants, then overwrites every element of the returned slice and asserts
  the next call still returns the four.
- `TestNewPublisherRefusesIncompleteWiring` (`publisher_test.go`) replaces `TestNewPublisher_RejectsIncompleteWiring`,
  which pinned the nil-publisher no-op. Each refusal returns an error and a nil publisher, and the error names what is
  missing (`bucket`, `key`). A control row builds a publisher with a bucket and a key and checks `Key()`.
- The five-family assertion is a subtest of `TestGauges_FullyQualifiedNamesPreserveTheWireContract`: a set built with
  `NewGauges("graph_ingest")`, registered on a `metric.MetricsRegistry` and given one `Set`, exposes exactly the five
  sorted family names `semengine_graph_ingest_{bootstrap_complete,lag,readiness,readiness_state,
  status_publish_failures_total}`. The `Set` is needed because a `GaugeVec` exposes no family until a label is set.
