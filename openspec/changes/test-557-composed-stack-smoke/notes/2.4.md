# Task 2.4 notes: `TestSmoke_BrokerRestartBetweenRuns`

Developer notes on the choices design D6, case 3, leaves open, and the "shown to fail" runs design D7 asks for.

## Choices the design leaves open

- **Its own NATS server.** The test restarts the server, which the package's shared one must not do, so it starts
  its own with `natsfixture.New` (`// Own server:` on the line above). The server keeps its container's writable
  layer across `Restart` (`natsfixture/restart.go`), so file-backed streams and buckets survive and memory-backed
  ones do not. Its `Start` and `Restart` need a bounded context; `brokerBudget` is an hour, an unreachable
  fallback, so a broker that never comes back ends at `go test -timeout`.
- **The URL is required unchanged** (`restartBrokerKeepingURL`, after graph-ingest's `restartKeepingURL`): Docker
  does not promise the host port, so a remapped one fails as the fixture's failure, naming both URLs.
- **The first boot runs in a subtest** (`first boot`), so its observer's connection is closed before the restart:
  `Restart`'s doc says a caller stops what it built on the URL first. After the restart a new observer opens on
  the same URL. The stack itself is stopped by SIGTERM before the restart, as the spec scenario says.
- **After the restart** the test requires: the same minted platform ID (the configuration bucket kept it), the
  four components listed, then `checkWritesAfterRestart`, the same helper as case 1. Its waits read the
  `ENTITY_STATES` revision after the new entity and the edit are acknowledged, so the envelopes left from the
  first boot cannot pass them; then health, the first batch's answers plus the two writes, and an embedding record
  for each at its current revision.
- **No answers are checked between the restart and the new writes**, for the reason in `notes/2.2.md`.
- **Passed on main**: no defect to file.

## Shown to fail (design D7)

never in the worktree. Each makes KV buckets memory-backed, which a stack restart on the same server cannot see
and a broker restart can. Each was run on case 3 and then on the other three tests, with:

