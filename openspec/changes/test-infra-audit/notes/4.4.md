# Task 4.4 notes

- **`natsclient` helper split (`natsclient/test_helpers_integration_test.go`):** `startFixture(t)` now takes no
  `natsfixture.Option`s and returns an unexported `sharedFixture` carrying only `URL() string` over `shared.Reset(t)`.
  That keeps the 44 `startFixture(t).URL()` call sites across the shared tests unchanged while ensuring `startFixture`
  serves shared tests only and exposes no `*natsfixture.Fixture`. `newFixtureClient(t)` resets the shared server and
  calls `newFixtureClientAt(t, url)`, which the three `WithMaxPayload` own-server tests in
  `natsclient/request_response_bounds_integration_test.go` also call after starting their own `natsfixture.New`.
  `(tc *fixtureClient).stream` creates its stream through `tc.Client.JetStream()`.
- **`processor/graph-ingest` shared helpers:** `newFixtureClient(t, streams...)` in
  `processor/graph-ingest/fixture_integration_test.go` calls `shared.Reset(t)`, opens the client through
  `natsfixture.Open(t, url, openFixtureClient)`, and creates each requested stream through `client.JetStream()`. The
  five shared tests that previously called `natsfixture.New(t)` only to reach `f.URL()` or `f.JetStream()`
  (`TestGraphIngestLifecycleSuite`, `startGraphIngestOnFixture`,
  `TestIntegration_Settlement_LongApplyIsNotRedelivered`,
  `TestIntegration_Settlement_ProcessKilledBetweenApplyAndAck`, and
  `TestIntegration_Settlement_FailedGuardWriteIsRedelivered`) now reset the shared server via `shared.Reset(t)` or
  `newFixtureClient(t, entityStream)` and inspect JetStream state through the test client's `JetStream()` handle. The
  two restart tests in `processor/graph-ingest/guard_generation_integration_test.go` keep `natsfixture.New(t)` with
  `// Own server: restarts the server mid-test.`.
