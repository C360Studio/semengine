# Task 3.1 Notes: `vocabulary` Extensions, Generated Checks, and Mutation Evidence

## Implementation Summary

Implemented in `vocabulary/`:

1. **Reverse IRI Lookup (`vocabulary/registry.go`)**:
   - `LookupByIRI(iri string) []string` returns a newly allocated, lexicographically sorted slice of canonical 3-part
     dotted predicates registered with `WithIRI(iri)`, or `nil` when `iri` is empty or unmatched.
   - Scans `predicateRegistry` under `registryMu.RLock()` so `predicateRegistry` remains the single source of truth
     across `Register`, amend, `ClearRegistry`, and `SnapshotRegistry`.
2. **Entity-Type Class Registration (`vocabulary/entity_type.go`)**:
   - `ParseEntityTypeKey(domainType string) (domain, entityType string, err error)` validates a 2-segment lower-kebab
     ASCII key `<domain>.<type>` using `validatePredicateSegment`.
   - `RegisterEntityType(domainType string, opts ...EntityTypeOption)` registers or amends `EntityTypeMetadata`
     (`WithEntityTypeDescription`, `WithClassIRI`, `WithSuperclass`), deduplicating `Superclasses` in registration order
     and panicking on invalid keys or empty/whitespace IRIs.
   - `GetEntityTypeMetadata`, `ListRegisteredEntityTypes`, and `LookupEntityTypesByClassIRI` return defensive copies and
     sorted results.
3. **Reified Ontology Projection (`vocabulary/projection.go`)**:
   - `ProjectionStep` and `ProjectionSpec` (`json` and `yaml` tags) model multi-hop reification chains (e.g. BFO/CCO
     `ActOfMeasuring` intermediate nodes) without storing blank nodes in `ENTITY_STATES`.
   - `WithProjection(spec ProjectionSpec)` deep-copies `spec` onto `PredicateMetadata.Projection`;
     `validatePredicateMetadataLocked` refuses empty step slices, empty/whitespace IRIs, missing `NodeClassIRI` on
     intermediate hops, or `ValuePredicateIRI` on non-terminal hops.
4. **Declarative JSON/YAML Vocabulary Packs (`vocabulary/pack.go`)**:
   - `LoadPackJSON` (`json.Decoder.DisallowUnknownFields`) and `LoadPackYAML` (`yaml.Decoder.KnownFields(true)`) decode
     `PackSpec` while refusing unknown fields, empty input, or trailing data/documents.
   - `PrefixSpec.Validate()` enforces W3C Turtle `PN_PREFIX` syntax on `Prefix` and valid `IRIREF` + URI scheme syntax
     on `Namespace` (`#237`), and `RegisterPack` (with batch `WithPrefixRegistrar(func([]PrefixSpec) error)`, e.g.
     `export.RegisterPrefixes`) stages and validates all prefixes, predicates (rejecting incompatible `alias_priority`
     without `is_alias` or `alias_type` `#251` and validating via shared `validatePredicateMetadataIn`, including a
     post-staging pass for intra-pack inverse consistency), and entity types before mutating `predicateRegistry`,
     `entityTypeRegistry`, or `export` prefixes (fail-closed, `#237`).
5. **Review-Round Fixes (`#237`, `#238`, `#239`, `#249`, `#250`, `#251`, `#252`)**:
   - `vocabulary/export/prefix.go` and `jsonld.go`: `RegisterPrefixes` atomically validates and registers a batch of
     `PrefixSpec` entries (`#237`); `compact` breaks equal-length namespace ties deterministically by lexicographically
     smallest prefix (`#238`) and only compacts local names satisfying W3C Turtle `PN_LOCAL` (`#250`);
     `jsonldContext()` emits explicit `{"@id": ns, "@prefix": true}` definitions for namespaces not ending in an RFC
     3986 `gen-delim` such as `BFO_` (`#249`); and `jsonldLiteralValue` preserves explicit `@value`/`@type` forms when
     native JSON boolean or number conversion cannot preserve the supplied lexical form and datatype (`#252`).
   - `vocabulary/export/object.go`: `dateTimeLexical` and `classifyByGoType` format `time.Time` with `time.RFC3339Nano`
     so fractional seconds survive `xsd:dateTime` export (`#239`, verified by `TestClassifyObject_DateTimeSubsecond` and
     Rapid property test `TestPropDeclaredDateTimeNeverFabricatesAnInstant` across `NTriples`, `Turtle`, and `JSONLD`
     after `roundTripThroughEntityStates`).
